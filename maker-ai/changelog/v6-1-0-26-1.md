## 🚀 New Features

• **Core**
🌐 `Change 15747` Novo parâmetro de segurança `Seguranca:Consulta:ValidarComandoSQL` para habilitar ou desabilitar a validação de comandos SQL nos componentes *Calendário* e *Card* e em consultas feitas nos sistemas. [Saiba mais!](../docs/dicas-e-truques/webrun/como_aumentar_a_seguranca_de_sua_aplicacao#segurancaconsultavalidarcomandosql)

• **API de Funções**
🔀 `Change 15749` Função *Abrir Consulta* passa a respeitar a validação configurável de comando SQL via propriedade avançada.
🔀 `Change 15748` Função *Abrir Consulta Não Gerenciada* passa a respeitar a validação configurável de comando SQL via propriedade avançada.
🔀 `Change 15750` Função *Abrir Consulta Navegável* passa a respeitar a validação configurável de comando SQL via propriedade avançada.

## 🐛 Bug Fix

• **Master Skin**
🌐 `Fix 15746` Correção do *Master Skin*, que não carregava corretamente quando o parâmetro `DebugCachedFiles` estava desativado.

• **API de Funções**
🔀 `Fix 10492` Correção da função *Envio de Envelope SOAP com Certificado Digital*, que interrompia o fluxo e exibia erro na tela quando a requisição retornava status HTTP 400; agora o retorno de erro é entregue na execução da regra, permitindo tratá-lo no fluxograma.
