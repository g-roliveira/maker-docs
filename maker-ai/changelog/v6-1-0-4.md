## 🚀 New Feature

• **Core**

🌐 `CHANGE 15213` Suporte a funcionalidade Assistente de Regras.
🌐 `CHANGE 15214` Atualização da versão mínima da API de Funções para a versão 17.0.1

• **Aba Localizar**

🌐 `CHANGE 15201` Suporte ao parâmetro *Nodo Legado* tem como principal objetivo abrir o formulário como em versões anteriores, na primeira aba.

• **FontAwesome**

🌐 `CHANGE 15210` Atualização para a versão 7.0.1.

• **Upload**

🌐 `CHANGE 15189` Upload de arquivos estava limitando o tamanho de arquivo que podiam ser upados para o servidor.

• **Report Server**

🌐`CHANGE 15205` Melhoria na abertura de relatórios quando o caminho para armazenamento do relatório possui espaço em branco.
