## 🚀 New Features

• **Core**

📝 `CHANGE 15273` Melhoria da definição de projetos com o charset UTF-8.
🔀 `CHANGE 15126` Inclusão da função *Executar Processamento*. Essa função executa um processamento de uma regra criada pelo *[Assistente de Regras](../docs/webrun/assistente_regras)* e que está armazenado no sistema.
🔀 `CHANGE 15173` Inclusão da função *Bootstrap - Trocar tema*. Essa função tem como principal objetivo alternar entre o tema claro e escuro.

• **Skins e Templates**

🌐 `CHANGE 15274` Melhoria na identificação do tema definido no Webrun para os recursos:

- Excel para Maker
- Interface de Webservices
- Interface de Autotest
- Interface de Ícones.

## 🐛 Bug Fix

• **Core**

📝 `FIX 15269` A estrutura do Menu não era exibida corretamente quando o projeto estava configurado com codificação UTF-8
📝 `FIX 15270` Em alguns casos, o erro *Unexpected server response* era exibido na abertura de um projeto.

• **Assistentes**

📝 `FIX 15271` Melhoria na criação de formulário via *assistente de criação de formulários*, em alguns casos não estava sendo possível utilizar o recurso após execução de prompts que geravam erros no armazenamento do histórico.

• **Grade**

🌐 `FIX 15268` Ao excluir um registro após a inclusão, o dado removido não correspondia à linha selecionada.

• **RSS**

🌐 `FIXS 15272` O componente RSS apresentava extensão excessiva na vertical em dispositivos móveis.
