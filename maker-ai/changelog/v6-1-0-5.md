## 🚀 New Feature

• **Skins e Templates - MasterSkin**

🌐 `CHANGE 15229` Melhorias na troca de temas claro e escuro.

• **Core**

🌐 `CHANGE 15232` Melhoria no carregamento de *cache* das customizações de layout do sistema por meio do Masterskin.

• **Chat**

🌐 `CHANGE 15238` Suporte para o envio de arquivos para os assistentes definidos no compoenente.

## 🐛 Bug Fix

• **Aba Localizar**

🌐 `FIX 10400` Colunas que possuem checkboxes e campos com apenas um dígito ficavam reduzidos.
🌐 `FIX 10399` Ao realizar a mesma busca no filtro único a indicação de filtro ativo e botão de apagar busca ficavam desativados.
🌐 `FIX 15236` Não era possível realizar uma busca no filtro único em banco de dados *Oracle*.
🌐 `FIX 15237` Ao editar um registro o status do formulário não estava sendo atualizado para em edição.

• **Grade**

🌐 `FIX 10402` Em alguns casos, ao tentar excluir um registro após inserção uma exceção (*Invalid Cursor Position*) ocorria.
🌐 `FIX 10396` Componente Grade apresenta exceção ao utilizar a função *Modificar Consulta do Formulário ou Grade*.
