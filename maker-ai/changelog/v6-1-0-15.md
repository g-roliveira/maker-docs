## 🚀 New Features

**AI - Inteligência Artificial**
📝 `Change 15258` Nova aba de sugestões de eventos do formulário devolvidos pelo Assistente de Formulários
📝 `Change 15290` O `Assistente de Formulários` agora é capaz de definir propriedades do formulário, tamanho dos formulários, posicionamento e tamanho dos componentes e demais propriedades dos componentes.
📝 `Change 15392` Melhoria na legibilidade do `Chat` do Assistente de Sistema.

• **Core**
🌐 `Change 15255` Nova funcionalidade de inclusão de dados no formulário a partir de leitura de imagens com inteligência artificial.
🌐 `Change 15276` Nova funcionalidade de duplicação de registro do formulário.
🌐 `Change 15273` Melhoria no encerramento da sessão do usuário com o WebSocket.
🌐 `Change 15321` Melhoria na escrita do log da aplicação, a partir dessa versão o log da aplicação estará unificado no arquivo *stdout*.
🌐 `Change 15329` Melhoria na exportação do sistema no formato *JAR*, arquivos de *debug* não eram ignorados na montagem do sistema de arquivos.
🌐 `Change 15331` Melhoria no desregistro do driver de conexão com banco de dados *MySQL* na finalização do servidor de aplicações.
🌐 `Change 15386` Melhoria na visualização da exceção na interface de *upload* de arquivos.
📝 `Change 15261` Melhoria no Assistente de criação de formulários para projetos Oracle.
📝 `Change 15277` Nova central de notificações no Maker para notificações sobre novas versões de template.
📝 `Change 15297` Novas propriedades para exibir/ocultar os botões de `Duplicar Registro` e `Incluir com IA` dos ícones na barra de navegação do formulário.
📝 `Change 15353` Nova opção *Converse com o Sistema* no menu Copilot (**apenas Maker No-Code**).
📝 `Change 15482` Melhoria no versionamento. A partir desta versão, o fluxograma será versionado na criação.

• **Imagem**
🌐 `Change 15348` Nova funcionalidade, a partir dessa versão, o componente permite realizar a leitura da imagem definida no componente por meio de *inteligência artifícial* e extrair dados para o formulário corrente.

• **Aba Localizar**
🌐 `Change 15448` Suporte a novos atalhos na aba de filtros avançados, sendo eles:

- **Enter** - Realiza a pesquisa.
- **Delete** - Apaga o filtro
- **Ctrl + Enter** - Adiciona um novo filtro

• **Listagem**
🌐 `Change 15288` Melhorias e novas funcionalidades para o componente:

- Melhor visualização do modal de configuração com *inteligência artifícial*.
- Personalização de relatório.
- Novo formulário de exibição das listagens.
- Ordenação alfabética dos itens.
- Atualização automaticamente do formulário de relatórios.
- Nova função: **Abrir listagem para impressão**.
- Inclusão do botão para cópia do GUID do relatório.
- Inclusão do botão para importar relatório.

• **Histórico de Alterações**
🌐 `Change 15354` Melhoria no carregamento de informações sobre os formulários do sistema.

• **API de Mensagens**
🌐 `Change 15352` Inclusão do collapse de detalhes quando o sistema está com o modo *DebugMode* ativo.

• **Play de Fluxo**
🌐 `Change 15355` Melhoria para que as modificações realizadas no fluxograma sejam refletidas na execução da regra pelo *Play de Fluxo*.

• **Master Skin**
🌐 `Change 15362` Opções de customização dos ícones novos da barra de navegação *Incluir com IA* e *Duplicar Registro*.

• **Menu**
🌐 `Change 15365` Suporte a definição de itens favoritos que se tornarão atalhos na aplicação.
🌐 `Change 15311` Melhoria na identificação dos relatórios do sistema carregados na interface de configurações do *Menu*.

• **Templates**
🌐 `Change 15366` Implementação do modal de favoritos do sistema.

- **Para adicionar um novo atalho**, no menu, clique no icone de estrela. Se a estrela estiver preenchida, esse item está marcado como favorito.
- **Para abrir o modal**, passe o mouse sobre a imagem presente no formulário principal.

• **API de Funções**
🔀 `Change 15312` Suporte a função *JSON - Filtrar Objeto* para a camada cliente.
🔀 `Change 15282` Suporte a função *Usuário é Administrador?*.
🔀 `Change 15283` Suporte a função *Atualizar Clipboard*.
🔀 `Change 15405` Suporte a função **XML - Obter Filhos de um Elemento Com Namespace**.
🔀 `Change 15412` Suporte a função **Árvore - Expandir Elemento**.
🔀 `Change 15388` Melhoria na função *JSON - Filtrar Objeto*, suporte aos operadores:

- (= ou equals) Igual a (comparação estrita de texto).
- (!= ou notequals) Diferente de.
- (&gt;) Maior que (comparação numérica, se possível).
- (&lt;) Menor que (comparação numérica, se possível).
- (&gt;=) Maior ou igual a (comparação numérica, se possível).
- (&lt;=) Menor ou igual a (comparação numérica, se possível).
- (contains) Contém o texto (não sensível a maiúsculas/minúsculas).
- (startswith) Começa com o texto (não sensível a maiúsculas/minúsculas).
- (endswith) Termina com o texto (não sensível a maiúsculas/minúsculas).
- (regex) Corresponde a uma expressão regular.

🔀 `Change 15363` Adição do parâmetro **Id do componente** para a função *Opções - Novo*.
🔀 `Change 15427` Melhoria na função **Destruir Componente**.

• **AI**

📝 `Fix 10456` Barra de progresso da atualização do contexto ficava presa ao cancelar o preview no Assistente de Criação de Formulários.

• **Core**
🌐 `Fix 15260` Melhoria no download de arquivo, em alguns casos, o arquivo não estava sendo encontrado no sistema de arquivos quando Versão Segurança está ativo.
🌐 `Fix 10422` Não estava sendo possível debugar um fluxograma na camada cliente com a sessão **Change**.
🌐 `Fix 10420` **Oracle**: Colunas do banco de dados do tipo *Clob* não estavam sendo carregados corretamente no *Histórico de Alterações*.
📝 `Fix 10414` **Oracle**: Correção na importação de FRZ em projetos Oracle que contém valor default em qualquer coluna no banco.
📝 `Fix 15287` Correção na geração do Manual do Sistema em projetos Oracle e SQLServer.

📝 `Fix 15328` Corrigido um erro na renderização do texto das mensagens do Chat do Assistente de Sistema.
📝 `Fix 10460` Menu superior do fluxograma não estava aparecendo com a tecla de atalho `ALT`.

• **Grade**
🌐 `Fix 10417` Exportação de dados não estava funcionando quando a consulta possuía constantes do sistema.
