## [📄️ Descritores](gerador_de_codigo/descritores)

Todo o processo de geração de código está baseado na construção dos Descritores. É importante conhecer o comportamento de cada um deles dentro do processamento do gerador.

## [📄️ Gerador de Código](gerador_de_codigo/gerador_de_codigo_)

Este recurso deve ser executado por usuários que conheçam a fundo a linguagem de banco de dados, que desejam gerar o código do fluxo para código do banco selecionado.
