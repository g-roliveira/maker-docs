## [📄️ PostgreSQL](banco-de-dados/postgresql)

A plataforma Maker AI foi atualizada para oferecer suporte completo ao ecossistema do PostgreSQL 17. Anteriormente limitado à versão 14, este avanço permite que desenvolvedores utilizem instâncias de banco de dados modernas (versões 15, 16 e 17) em seus projetos.

## [📄️ DB2 9.5](banco-de-dados/utilizando_db2_no_maker)

Para utilizar o banco DB2 no Maker é necessário ter o CLIENT instalado na máquina de desenvolvimento.

## [📄️ Firebird 2.5.1 ... 2.5.9](banco-de-dados/utilizando_o_firebird)

O Maker suporta a bases de dados Firebird da versão 2.5.1 até a versão 2.5.9. A sua utilização é muito simples, basta que o Servidor de Banco de Dados esteja devidamente instalado e configurado para tal.
