## [📄️ Arquivo ADMIN.XML](Pasta_CONFIG/arquivo_admin_xml)

Neste arquivo, é possível fazer a alteração do Login e da Senha do administrador que tem acesso às Configurações no Webrun. Este arquivo encontra-se na pasta C:\Arquivos de programas\Maker Studio Bootstrap\Webrun Studio Bootstrap\config.

## [📄️ Arquivo CONFIG.XML](Pasta_CONFIG/arquivo_config_xml)

Este arquivo registra as configurações definidas na tela Parâmetros de Configuração.

## [📄️ Arquivo DATABASES.XML](Pasta_CONFIG/arquivo_databases_xml)

As declarações das chaves de conexão encontram-se nas tags group. Este arquivo está composto pelas chaves de conexão com os bancos de dados que o Webrun suporta.

## [📄️ Pasta SAVED do Webrun](Pasta_CONFIG/pasta_saved_do_webrun)

Nesta pasta, são registradas configurações do Webrun, referentes à personalização de Grid, Pesquisas Avançadas, Atalhos. Esta pasta encontra-se em C:\\Arquivos de programas\\Softwell Solutions\\Maker Studio Bootstrap\\Webrun Studio Bootstrap\\config\\saved.
