Para acessar o Webrun e abrir um projeto desenvolvido no Maker, siga os passos:

1. Abra o Navegador.
2. Na Barra de Endereço do navegador, digite o endereço do Webrun (para mais detalhes, acesse o tópico [Acessando Webrun](acessando_webrun)):

![image1459.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1459.jpg)

3. Na tela Sistemas:

1. Selecione o sistema pelo campo Escolha dentre os sistemas disponíveis.
2. Clique no botão ![image501.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image501.gif). Para mais detalhes, acesse o tópico [Efetuando logoff do usuário no sistema](efetuando_logoff_usuario_sistema).

Alterando Imagens da Tela de escolha dos Sistemas

É possível alterar a imagem de fundo e também do banner da tela de seleção de sistema na pasta "Resource"continda no contexto do Webrun, modificando respectivamente as imagens "enterprise.jpg" e banner.jpg.

Imagem de fundo:

![image1460.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1460.jpg)

Banner:

![image1461.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1461.jpg)

Observações:

1. A imagem alterada na pasta Resource deve conter o mesmo tamanho da original. Após a alteração é necessário efetuar a limpeza de cache para que a imagem seja modificada.
2. Para mais detalhes sobre Escolha dentre os sistemas disponíveis, acesse o tópico [Instalação do Maker](../maker_2/instalacoes/instalacao_do_maker).
3. Para mais detalhes sobre a pasta de projetos, acesse o tópico [Acessando o Maker 2.0](../maker_2/acessando_o_maker_2.0).
4. Para atualizar a lista de projetos, obtenha mais informações no tópico [Atualizando a lista de sistemas do Webrun](atualizando_lista_sistemas_webrun).
