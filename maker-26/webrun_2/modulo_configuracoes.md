Após ter acessado a tela Tela de Configuração, é apresentada a tela Configuração do Sistema &lt;sigla do sistema&gt;:

![image1457.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1457.jpg)

A tela é composta pelas seguintes opções:

- Campo Instância - apresenta o nome da instância definida para o sistema. Essa informação pode ser complementada pelo tópico [Configurações](../maker_2/configuracao_das_conexoes/configuracoes);
- Campo Servidor - apresenta o nome do servidor de acesso onde a base de dados do projeto selecionado está armazenada;
- Campo Banco - informa o nome do banco de dados do projeto selecionado;
- Campo Usuário - informa o nome do usuário master de acesso ao banco de dados do projeto selecionado;
- Campo Senha - informa a senha do usuário master de acesso ao banco de dados do projeto selecionado;
- Botão ![image578.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image578.gif) - retorna à [Tela de Configuração](tela_configuracoes);

- Botão ![image579.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image579.gif) - este recurso permite a [Geração do Código-Fonte](../recursos_avancados/geracao_codigo_fonte/geracao_codigo_fonte) de um projeto;
- Botão ![image570.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image570.gif) - verifca os fluxos que estão sendo executados no servidor de aplicações, pelo Webrun, para o projeto selecionado. Para mais informações, acesse o tópico [Fluxos em execução no Webrun](fluxos_execucao_webrun);
- Botão ![image580.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image580.gif) - reinicia o serviço de acesso e processos do projeto selecionado;
- Botão ![image577.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image577.gif) - executa atualização das modificações que ocorram nos campos da tela.
