Acesse uma série de Configurações do Webrun pelo botão ![image499.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image499.gif):

![image1456.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1456.jpg)

A Tela de Configuração possui as seguintes opções:

- Botão ![image568.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image568.gif) - este botão atualiza a lista de projetos (mais detalhes no tópico Atualizando a lista de sistemas do Webrun);
- Botão  ![image569.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image569.gif) - acesse a tela Configuração do Sistema - XXX. Para mais informações, acesse o tópico Módulo de Configurações;
- Botão ![image570.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image570.gif) -  exibe os fluxos que estão sendo executados no servidor. Para mais informações, acesse o tópico Fluxos em execução no Webrun;
- Botão ![image571.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image571.gif) -  exibe a lista de sistemas que podem ser gerenciados (adicionar novo sistema na lista, excluir ou mesmo recarregar). Para mais informações, acesse o tópico Gerenciando Sistemas no Webrun;
- Botão ![image572.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image572.gif)- Em Parâmetros de Configurações, o usuário avançado poderá determinar configurações gerais para a execução de todos os sistemas no Webrun. Para mais informações, acesse o tópico Parâmetros de Configuração.

## Tela de Configuração Avançada

Após ter clicado em ![image569.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image569.gif) e ao clicar no link "Configuração Avançada" na tela "Configuração do sistema - &lt;Sigla do Sistema&gt;" será aberto mostrando de imediato os parâmetros utilizados pela "Conexão Principal". Na mesma tela consta:

![image265.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image265.jpg)

- O botão ![image573.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image573.gif) - é utilizado para a criação de um novo parâmetro para a conexão que estiver selecionada. Ao ser selecionado, abrirá a tela Prompt do usuário do Explorer:

![image266.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image266.jpg)

- O botão ![image574.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image574.gif) - clicando sobre este link, será apresentada uma caixa de seleção onde é possível selecionar a configuração que se quer modificar:

![image575.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image575.gif)

- O botão ![image576.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image576.gif) - exclui o parâmetro;
- O botão ![image577.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image577.gif) - clicando neste botão, todas as modificações efetuadas na conexão que estavam selecionadas serão confirmadas (gravadas) e a tela "Configuração do sistema - &lt;Sigla do Sistema&gt;" se fechará. Ademais, aparecerá, em seguida, uma mensagem de alerta que solicita o reinício do sistema; assim todas as alterações feitas na configuração serão observadas:

![image267.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image267.jpg)
