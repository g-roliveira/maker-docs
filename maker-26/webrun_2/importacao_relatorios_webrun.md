Este recurso, por meio do qual se podem importar relatórios para o sistema atual, está habilitado para usuários com permissão de administrador.

Para acessar este recurso, siga os passos:

1. [Acesse o Webrun](acessando_webrun).
2. [Acesse um sistema com privilégios de administrador](acessando_sistema_webrun).
3. Execute clique duplo no botão ![image562.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image562.gif) Importação de Relatórios. Será exibida a tela Importação com as seguintes opções:

1. Campo  Arquivo - informe o endereço do arquivo *.FRZ gerado na [Exportação](../maker_2/importacao_e_exportacao/exportacao) do relatório. Utilize o botão ![image563.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image563.gif) para abrir a tela Enviar Arquivo, auxiliando na localização do arquivo desejado.
2. Botão ![image564.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image564.gif) - clique neste botão após selecionar o arquivo de importação. Na parte inferior da tela será exibido:

   1. Sistema - sigla do sistema do(s) relatório(s) do arquivo de importação;
   2. Criação - data e hora de criação do arquivo de importação;
   3. ![image565.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image565.gif) - clique no ícone da pasta e uma tela apresentará a estrutura do menu do sistema em forma de árvore. Selecione o local onde o relatório será inserido. Utilize a opção Posicionar para indicar depois de ou antes de definindo assim o posicionamento do(s) relatório(s);
   4. Aba Relatórios - selecione o(s) relatório(s) que deseja importar. Utilize o campo ![image566.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image566.gif) para auxiliar na seleção de todos os relatórios do arquivo de importação;
   5. Botão ![image567.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image567.gif) - clique neste botão para efetivar a importação do(s) relatório(s) selecionados.
