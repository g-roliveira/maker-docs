Este recurso está habilitado para todos os usuários e permite que seja executado um logoff do sistema para a entrada de outra identificação de usuário.

Para acessar este recurso, siga os passos:

1. Em um sistema logado, clique no botão ![image532.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image532.gif) e será exibida a tela de acesso ao sistema:

![image1469.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1469.jpg)

2. Informe o nome e a senha do usuário;
3. Clique em ![image501.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image501.gif).

Observações:

1. O botão ![image502.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image502.gif) é para ativar o dispositivo de leitura biométrico;
2. O botão ![image533.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image533.gif) - retorna para a tela Sistemas, onde é possível selecionar um projeto.
