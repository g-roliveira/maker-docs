# Aba Visualização - visualiza e imprime relatórios

Na aba Visualização, podemos apresentar o relatório desenvolvido (imagem ilustrativa abaixo):

![image195.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image195.jpg)

São componentes que integram a aba Visualização:

- Os botões (todas as descrições abaixo dizem respeito à ação de execução de um clique sobre o botão):
- - ![image352.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image352.gif) - aparece a tela Imprimir, na qual é possível definir parâmetros relativos à impressão e imprimir o relatório;
  - ![image353.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image353.gif) - ao clicar neste botão, aparece a imagem abaixo. Este botão tem a funcionalidade de Procurar no texto palavras ou letras exibidas no relatório:

![image354.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image354.gif)

Após ter digitado o texto em &lt;FindText&gt;, clique no botão ![find text](https://suporte.softwell.com.br/Manual/Maker2_6/image355.gif) para procurar. O botão: ![image356.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image356.gif) - mostra a primeira palavra/letra informada no relatório; ![image357.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image357.gif) - mostra a palavra/letra anterior informada no relatório; ![image358.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image358.gif) - mostra a palavra/letra posterior informada no relatório; ![image359.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image359.gif) - mostra a última palavra/letra informada no relatório. O botão ![done](https://suporte.softwell.com.br/Manual/Maker2_6/image360.gif) finaliza a procura no texto.

- ![image361.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image361.gif) Página inteira - a visualização da imagem do relatório é redimensionada para o tamanho da apresentação de uma página inteira;
- ![image362.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image362.gif) Largura da página - a visualização da imagem do relatório é redimensionada para o tamanho da largura da aplicação;
- ![image364.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image364.gif) 100% - a visualização da imagem do relatório é redimensionada para o tamanho real da página;
- ![image365.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image365.gif) - Controle composto pelos seguintes itens: Primeira página (será apresentada a primeira página do relatório), Página anterior (será apresentada a página anterior à que estiver aparecendo), Próxima página (será apresentada a página posterior à que estiver aparecendo), Última página: será apresentada a última página do relatório;
- A imagem abaixo só aparece quando são criados [filtros de pesquisa na fonte de dados (aba Dados)](aba_dados_-_definindo_dados_para_relatorio). Após a execução de uma pesquisa, para que o filtro de pesquisa apareça novamente, é necessário navegar para qualquer uma das outras abas do Gerador de Relatórios e voltar para a aba Preview. Para a imagem abaixo, foi escolhido o tipo Lista Dinâmica:

![image196.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image196.jpg)

- ![image366.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image366.gif) - o botão está com sua funcionalidade desabilitada temporariamente;
- ![image367.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image367.gif) - apresenta a porcentagem da aparência do relatório relativa ao seu tamanho real (100%). Pode ser editada pelo usuário.

Para maiores informações sobre a visualização do relatório pelo Webrun, pode ser consultado o item [Configurações para exibição](../../webrun_2/relatorio/configuracoes_exibicao).
