Descrição:

Esta função abre uma nova conexão com a referência de uma conexão passada como parâmetro. Caso nenhuma conexão seja informada, será feita uma nova conexão com a conexão principal do sistema.

Parâmetros:

1. Conexao (Opcional).

![image1865.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image1865.gif)

Retorno:

Conexão (Variante)

Observação:

Caso deseje abrir uma nova conexão com um banco que não seja o principal, deve-se usar as funções "Abrir Conexão"da categoria "Banco de Dados".

Nome Real:

ebfGetNewConnection.

Compatibilidade:

Servidor.
