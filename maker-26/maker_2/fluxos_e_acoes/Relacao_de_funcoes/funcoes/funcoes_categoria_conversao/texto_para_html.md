Descrição:

Converte um texto para o formato HTML.

Parâmetros:

1. Texto que será convertido.

![image1301.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image1301.gif)

Retorno:

Texto no formato HTML. (Letras)

Observação:

HTML é uma linguagem de marcação utilizada para produzir páginas na Web.

Exemplo:

Assumindo como parâmetro a variável "Texto", o retorno será o conteúdo da variável "Texto" convertido para o formato HTML.

Nome Real:

ebfStringToHTMLString

Compatibilidade:

Todas as camadas
