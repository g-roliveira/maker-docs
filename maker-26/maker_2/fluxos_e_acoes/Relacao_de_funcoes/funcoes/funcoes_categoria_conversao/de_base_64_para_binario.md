Descrição:

Converte um Texto codificado na Base64 para Binário. A Base 64 é usada para codificar dados.

Parâmetros:

1. Texto em Base 64

![image1281.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image1281.gif)

Retorno:

O Texto em formato binário. (Variante)

Exemplos:

Assumindo como parâmetro o texto codificado em Base 64 TWFrZXI=, o retorno será  o binário correspondente a essa expressão.

Nome Real:

ebfBase64ToBinary

Compatibilidade:

Banco de dados e Servidor
