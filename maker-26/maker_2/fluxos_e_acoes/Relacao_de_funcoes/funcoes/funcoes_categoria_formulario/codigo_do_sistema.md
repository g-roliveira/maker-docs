Descrição:

A função retorna o Código (ou sigla) do sistema atual em que o fluxo está sendo desenvolvido (3 letras).

Parâmetros:

Não Possui.

![image1468.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image1468.gif)

Retorno:

Retorna o código (ou sigla) do sistema  utilizado.

Exemplo:

Se o fluxo estivesse sendo desenvolvido no Sistema de Contabilidade Pública o código do Sistema seria "CTP" (Letras).

Nome Real:

ebfGetSystemID

Compatibilidade:

Cliente e Servidor
