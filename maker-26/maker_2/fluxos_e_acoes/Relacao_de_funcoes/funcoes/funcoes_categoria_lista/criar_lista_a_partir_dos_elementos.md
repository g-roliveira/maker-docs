Descrição:

Essa função cria uma lista com todos os valores que foram passados pelos parâmetros.

Parâmetros:

1. Elemento da Lista

2. Elemento da Lista

![image1252.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image1252.gif)

Retorno:

Lista com todos os valores passados por parâmetro. O retorno dessa função deve ser armazenado numa variável

do tipo variante.

Observações:

1. A função pode ter (N) parâmetro.

2. O acesso aos elementos da lista retornada é feito através de outras funções da categoria lista.

Exemplos:

1. Assumindo os parâmetros como sendo 10, 2 e 5, o retorno será uma lista com os elementos 10,2 e 5.

2. Assumindo os parâmetros como sendo A, B e D, o retorno será uma lista com os elementos A, B e D.

Nome Real:

ebfListParamsCreate

Compatibilidade:

Cliente e Servidor
