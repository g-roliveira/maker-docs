O Filter Builder é utilizado para realizar pesquisas customizadas dentro de uma determinada consulta.

![image1196.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1196.jpg)

A tela do Filter Builder é composta pelas seguintes opções:

- Filter - Ao ser clicado é demonstrado ao usuário as seguintes opções:
- - Add condition - adiciona a condição;
  - Add  Group - adiciona o grupo;
  - Clear ALL - limpa todas as pesquisas criadas.

Campo em que será feito a consulta:

Condição para a execução da consulta:

![image1199.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1199.jpg)

Campo que determinará o quê será buscado:

![image1200.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1200.jpg)

- press the button to add a new condition - ao ser clicado é adicionada uma nova condição de busca.
- Open... - abre um filtro previamente criado e salvo.
- Save As... - salva o filtro criado no formato.flt.
- OK - salva as configurações feitas e fecha a tela do filter builder.
- Cancel - cancela as configurações feitas.
- Apply - aplica as configurações efetuadas.

Custom Filter

![image1249.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1249.jpg)

Acessado a partir de qualquer tela que contenha a aba localizar este recurso é utilizado para realizar pesquisas em determinadas condições.

Para acessá-la clique no campo em que será feito a pesquisa e em seguida selecione Custom, como demonstra a figura abaixo:

![image1251.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image1251.jpg)

Observação: A pesquisa por meio do Filter Builder é Case Sensitive.
