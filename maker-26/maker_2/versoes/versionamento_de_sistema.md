Nesta tela é possível auditar as versões dos formulários, fluxos, relatórios e menus. Por essa tela, é possível restaurar versões desses objetos ou mesmo versionar todo o projeto.

![image775.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image775.jpg)

A grade da tela traz as seguintes informações:

- Data e Hora - exibe a data e a hora em que o objeto foi atualizado;
- Tipo - exibe os ícones representativos de cada objeto. Os tipos são:
- - ![image795.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image795.gif) Formulário;
  - ![image796.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image796.gif) Fluxo;
  - ![image797.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image797.gif) Relatório;
  - ![image798.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image798.gif) Menu;
  - Sem ícone - representa o versionamento do sistema completo.

- Descrição - exibe uma descrição sobre o objeto, identificando com o tipo e o nome entre aspas.
- Versão - exibe a quantidade de vezes em que o objeto foi atualizado. Essa quantidade é determinada na aba [Versionamento](../configuracao_das_conexoes/configuracoes#versionamento) da tela [Configurações](../configuracao_das_conexoes/configuracoes);
- Usuário - identifica o usuário que atualizou o objeto.

A tela traz as seguintes opções:

- ![arquivar o sistema atual](https://suporte.softwell.com.br/Manual/Maker2_6/image799.gif) - Ao clicar nesse botão, será gerada uma versão do projeto, com todos os objetos (formulários, relatórios, fluxos, menus). Após clicar no botão, defina uma descrição na tela Descrição da Versão;
- ![restaurar](https://suporte.softwell.com.br/Manual/Maker2_6/image800.gif) - Restaura uma versão selecionada na grade;
- ![imprimir](https://suporte.softwell.com.br/Manual/Maker2_6/image801.gif) - Exibe e permite imprimir um relatório listando o versionamento dos objetos do projeto;
- ![fechar](https://suporte.softwell.com.br/Manual/Maker2_6/image802.gif) - Fecha a tela Versionamento do sistema.

Observações:

1. Clicando com o botão direito do mouse sobre um registro da grade da tela Versionamento do sistema, é exibido um menu pop-up com as seguintes opções:

a. Restaurar - possui a mesma função do botão descrito anteriormente;

b. Renomear - permite redefinir a descrição;

c. Salvar como arquivo de exportação (*.FRZ) - gera um arquivo que pode ser utilizado com a função [Importar](../importacao_e_exportacao/importacao);

d. A tela Versionamento do sistema possui teclas de atalho, onde:

- Alt + A serve para ![arquivar o sistema atual](https://suporte.softwell.com.br/Manual/Maker2_6/image799.gif);

- Alt + R serve para ![restaurar](https://suporte.softwell.com.br/Manual/Maker2_6/image800.gif);

- Alt + P serve para ![imprimir](https://suporte.softwell.com.br/Manual/Maker2_6/image801.gif);

- Alt + F serve para ![fechar](https://suporte.softwell.com.br/Manual/Maker2_6/image802.gif).

e. Ao selecionar Histórico da [paleta Objetos](../paleta_objetos), clicando com o botão direito do mouse sobre qualquer objeto, é exibida a tela Versionamento do sistema. Nessa tela não será mostrado o botão ![arquivar o sistema atual](https://suporte.softwell.com.br/Manual/Maker2_6/image799.gif) e os registros da grade se restringem às versões armazenadas do objeto selecionado.
