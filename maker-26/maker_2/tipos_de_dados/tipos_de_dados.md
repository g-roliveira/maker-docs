Esta tela permite definir Máscaras para formatação da exibição de dados para formulários. Acesse esse recurso por meio do menu Projeto e deste clique em Tipos de Dados.

![image69.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image69.gif)

A tela possui uma Barra de Ferramentas para a navegação e edição dos registros e os seguintes campos:

- Descrição - local para determinar o nome da máscara;
- [Máscaras](../mascaras)- é a expressão que define a aparência dos dados apresentados nos campos (componentes) do formulário. Abaixo consta uma imagem que exemplifica a utilização da máscara no campo CPF:

![image917.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image917.jpg)

Observações:

1. A máscara de CPF só se aplica a campos do tipo VARCHAR.
2. As máscaras CPF e CNPJ servem para formatação dos componentes e validação das informações. Ao inserir os dados nos campos vinculados às máscaras e gravá-los, é lançada uma mensagem de erro se os valores forem inválidos;
3. O Webrun se baseia pelos nome CPF ou CNPJ para efetuar a validação, caso o desenvolvedor modifique o nome desses tipos, não ocorrerá validação.
