Este exemplo irá descrever como criar relatório com Código de Barras.

Para este exemplo, foi criada uma tabela Patrimônio contendo os campos: Código do Produto, Descrição do Produto e Cod_Barra.

Utilizando o Assistente de criação de formulários, defina o nome para o formulário e associe Fonte de Dados PATRIMONIO:

![image461.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image461.jpg)

Criar um relatório (legado) para listar o Código de Barra.

Após seleção de todos os campos da tabela PATRIMONIO no menu Arquivo, em Novo, clique na aba Desenho. Na área Detalhe, coloque os componentes ![image686.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image686.gif) (Texto) , ![image687.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image687.gif) (Campo com Código de Barras) e ![image688.gif](https://suporte.softwell.com.br/Manual/Maker2_6/image688.gif) (Imagem):

![image462.jpg](https://suporte.softwell.com.br/Manual/Maker2_6/image462.jpg)
