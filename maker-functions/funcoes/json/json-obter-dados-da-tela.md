## Descrição

Esta função obtém um JSON dos dados dos componentes em tela.

Parâmetro:
Não possui.

## Retorno

Objeto JSON. (Variante)

## Observação

O nome do componente corresponde a chave do JSON e o valor corresponde ao valor da chave.
