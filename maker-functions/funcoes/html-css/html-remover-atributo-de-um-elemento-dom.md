## Descrição

Esta função remove um atributo de um objeto HTML (DOM).

## Parâmetro(s)

1. Referência do elemento. (Variante)
2. Nome do Atributo. (Letras)

## Retorno

Verdadeiro, se exclusão bem sucedida, caso contrário, falso. (Lógico)
