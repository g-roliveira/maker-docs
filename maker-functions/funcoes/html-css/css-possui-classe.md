**Compatibilidade:** Cliente

## Descrição

Esta função verifica se um elemento passado por parâmetro possui uma classe CSS.

## Parâmetro(s)

1. Referência do Elemento. (Variante)
2. Nome da classe CSS a ser verificada. (Letras)

## Retorno

Não possui.
