**Categoria:** [Utilitário](../../categorias/utilitario)

**Compatibilidade:** Servidor

## Descrição

Realiza uma requisição POST para remover usuário(s) do sistema de gerenciamento do relógio de ponto.

## Parâmetros

1. URL da requisição. (Letras)
2. Estrutura JSON com dados do(s) usuário(s) que devem ser removidos. (Variante)

## Retorno

JSON com o retorno do servidor acerca da remoção dos usuários (Variante)

## Observação

Para maiores informações sobre a estrutura JSON que deverá ser passada, consulte a documentação:
https://www.controlid.com.br/suporte/api_idclass_latest.html#53_remove_users
