## Descrição

Realiza uma requisição POST para verificar a validade de uma sessão ativa no sistema de gerenciamento do relógio de ponto.

## Parâmetro(s)

1. URL da requisição. (Letras)
2. Código da sessão. (Letras)

## Retorno

JSON com o retorno do servidor sobre a validação da sessão (Variante)
