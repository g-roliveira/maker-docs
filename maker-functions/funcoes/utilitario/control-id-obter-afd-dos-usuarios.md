**Compatibilidade:** Servidor

## Descrição

Realiza uma requisição POST para obter os dados do Arquivo Fonte de Dados (AFD) do sistema de gerenciamento do relógio de ponto.

## Parâmetros

1. URL da requisição. (Letras)
2. Código da sessão. (Letras)

## Retorno

JSON Array com o retorno da requisição. (Variante)
