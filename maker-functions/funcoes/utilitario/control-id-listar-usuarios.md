**Categoria:** [Utilitário](../../categorias/utilitario)

**Compatibilidade:** Servidor

## Descrição

Realiza uma requisição POST para listar os usuários cadastrados no sistema de gerenciamento do relógio de ponto.

## Parâmetros

1. URL da requisição. (Letras)
2. Estrutura JSON com parâmetros da listagem que deverá ser retornada (Variante)

## Retorno

JSON contendo o retorno da requisição. (Variante)

## Observação

Para maiores informações sobre a estrutura JSON que deverá ser passada, consulte a documentação:
https://www.controlid.com.br/suporte/api_idclass_latest.html#52_load_objects
