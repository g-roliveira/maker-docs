## Descrição

Realiza uma requisição POST para obter a quantidade total de usuários cadastrados no sistema de gerenciamento do relógio de ponto.

## Parâmetros

1. URL da requisição. (Letras)
2. Código da sessão. (Letras)

## Retorno

JSON com o retorno da requisição. (Variante)
