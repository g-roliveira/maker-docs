**Compatibilidade:** Cliente

## Descrição

Chama um Web Service (são componentes que permitem às aplicações enviar e receber dados em formato XML) para
aplicações em dispositivos móveis.

## Parâmetro(s)

1. URL do Web Service (possibilita conexão com https).
2. Parâmetro de entrada do Web Service.
3. Encoding da requisição, que neste caso sempre será JSON.

## Retorno

Letras.
