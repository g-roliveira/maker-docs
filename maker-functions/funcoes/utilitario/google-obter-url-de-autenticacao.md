**Categoria:** [Utilitário](../../categorias/utilitario)

**Compatibilidade:** Servidor

## Descrição

Retorna a URL necessária para realizar a autenticação do usuário via Google

Parâmetro:
Não possui.

## Retorno

URL para validação do Google (Letras)

## Observação

É necessário a definição correta dos parâmetros do Webrun de acordo com os parâmetros necessários definidos a partir dos dados do Google Console. Para mais informações, acesse https://manual.softwell.com.br/docs/webrun/login_google
