**Categoria:** [Utilitário](../../categorias/utilitario)

**Compatibilidade:** Servidor

## Descrição

Realiza uma requisição POST para adicionar um novo usuário ao sistema de gerenciamento do relógio de ponto.

## Parâmetros

1. URL da requisição. (Letras)
2. Estrutura JSON com os dados do usuário. (Variante)

## Retorno

JSON com o retorno do servidor acerca do cadastro do usuário. (Variante)

## Observação

Para maiores informações sobre a estrutura JSON que deverá ser passada, consulte a documentação:
https://www.controlid.com.br/suporte/api_idclass_latest.html#50_create_objects
