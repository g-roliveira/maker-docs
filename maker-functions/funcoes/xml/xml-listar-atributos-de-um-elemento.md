## Descrição

Esta função obtém todos os atributos (caso exista) no nó passado como parâmetro.

Parâmetro:
1. Nó XML. (Variante)

## Retorno

Lista com o nome dos Atributos do nó. (Variante)

## Observação

É recomendada sua utilização após a função Filhos de um elemento XML.
