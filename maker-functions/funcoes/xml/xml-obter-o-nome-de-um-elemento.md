**Categoria:** [XML](../../categorias/xml)

**Compatibilidade:** Cliente, Servidor

## Descrição

Obtém o nome de um elemento XML.

Parâmetro:
1. Objeto XML. (Variante)

## Retorno

Nome do Elemento. (Letras)

## Exemplo

Se temos
"&lt;TEXTO&gt;
Maker Flow Versão = 3.0
&lt;/TEXTO&gt;"
o retorno será: "TEXTO".
