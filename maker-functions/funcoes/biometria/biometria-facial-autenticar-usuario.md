**Categoria:** [Biometria](../../categorias/biometria)

**Compatibilidade:** Servidor

## Descrição

Essa função autentica o usuário no método 1:N, a partir dos parâmetros apresentados.

## Parâmetros

1. Imagem do usuário em bytes. (Variante)
2. Lista ou JSON com imagens de referência para validação. (Variante)
3. Redirecionar para o formulário principal? (Lógico)
4. Conexão. (Variante, Opcional)

## Retorno

Parâmetro Verdadeiro ou Falso, de acordo com o resultado da validação.
