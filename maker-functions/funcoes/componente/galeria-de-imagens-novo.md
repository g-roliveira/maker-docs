**Categoria:** [Componente](../../categorias/componente)

**Compatibilidade:** Servidor

## Descrição

Essa função cria um componente Galeria de Imagens dinamicamente.

## Parâmetro(s)

1. Nome do Componente.
2. Consulta SQL.
3. Campo ID. (Letras)
4. Campo Miniatura. (Letras)
5. Campo Imagem. (Letras)
6. JSON Propriedades. (Variante)

## Retorno

Não possui.

## Observação

O JSON de propriedades deve seguir o modelo abaixo:

"Fonte de dados": "",
"Barra de Rolagem":"",
"Altura Miniatura":"",
"Tamanho Miniatura":"",
"Permitir Upload":"",
"Permitir Exclusão":"",
"Expandir ao Clicar":"",
"Aba":"",
"Posição X":"",
"Posição Y":"",
"Altura":"",
"Tamanho":"",
"Habilitado":"",
"Visível":""
