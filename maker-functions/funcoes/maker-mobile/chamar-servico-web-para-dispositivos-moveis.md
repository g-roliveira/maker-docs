**Categoria:** [Maker Mobile](../../categorias/maker-mobile)

**Compatibilidade:** Servidor

## Descrição

Chama um Webservice que são componentes que permitem às aplicações enviar e receber dados em formato XML, para aplicações
em dispositivos móveis.

## Parâmetro(s)

1. URL do Web Service. (Letras)
2. Porta. (Letras)
3. Nome do Método. (Letras)
4. Lista contendo o nome dos parâmetros esperados para o Webservice. (Variante)
5. Lista contendo os valores para cada parâmetro definido no item 4. (Variante)

## Retorno

Retorna o resultado da chamada do serviço web. (Variante)

## Observação

No 1º Parâmetro deve sempre ter "http://" antes.
