Para os projetos desenvolvidos com a versão 3.8.0.60 e anteriores, é necessário efetuar a importação dos arquivos "Template - Atalhos" e "Template - Localizar"
em cada projeto para obter as correções do Template Localizar e manter o fluxos auxiliares de acordo com a versão do Webrun.
Para realizar este procedimento, siga os passos abaixo:

#### Template Auxiliares

- Baixe o arquivo [Template - Auxiliares](http://download.softwell.com.br/suporte/exemplos/Templates_Auxiliares.frz)
- Importe o arquivo baixado no projeto desejado

#### Template Localizar

- Baixe o arquivo [Template - Localizar](http://download.softwell.com.br/suporte/exemplos/Template_Localizar.FRZ)
- Importe o arquivo baixado no projeto desejado

Após importação, reinicie o serviço do Webrun e efetue a limpeza do cache do browser. Lembrando que é necessário estar com a API de funções
e o Webrun atualizados!
