- **Agora é possível filtrar os componentes Maker 3 utilizando a constante :COMPONENTE. O valor de um componente pode ser passado como critério para filtrar os dados dos componentes.**
- **Essa funcionalidade permite que ao navegar entre os registros, os componentes Maker 3 que possuem fonte de dados sejam recarregados.**
