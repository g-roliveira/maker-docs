# Identificação de Parâmetros no Montador de Expressões

Com o Maker 3.5 foi implementada a funcionalidade de identificação da posição do parâmetro no Montador de Expressões. Desta forma, ao chamar funções com uma
certa quantidade de parâmetro, a identificação visual da posição facilitará o seu preenchimento.

Para perceber a nova funcionalidade, abra o editor de fluxo utilizando o atalho F7;
