# Nova propriedade para o componente imagem.

## Lente de Aumento

A propriedade Lente de Aumento possibilita o usuário fazer uma inspeção mais detalhada da imagem exposta pelo componente.

Para configurar esta nova propriedade o desenvolvedor deve definir a altura e Largura do zoom em pixels.
