# Responsividade nos Formulários.

Essa propriedade permite que o formulário seja ajustado automaticamente.

Para que essa funcionalidade tenha o comportamento correto, a propriedade Centralizado Horizontal deve estar desabilitada (Centralizado Horizontal = Não). Essa funcionalidade só se aplica aos componentes Maker All presentes no formulário.

Para ativar a funcionalidade, abra as propriedades do formulário e modifique para Responsivo = Sim.

A responsividade se aplica tanto a aplicações web quanto mobile.
