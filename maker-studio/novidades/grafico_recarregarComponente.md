A partir da versão 3.8.1.20, o componente Gráfico (GoogleCharts) tem uma nova função adicional "Gráfico - Recarregar Componente", esta função deve ser utilizada
para atualizar o componente gráfico vinculado a componentes que não possuem fonte de dados.
