# Funções para manipulação de arquivo Word

O Word é o aplicativo mais utilizado para editar os mais diversos tipos de textos, como cartas, memorandos e documentos. Possui inúmeros recursos capaz de auxiliar o usuário a criar, formatar e manipular textos

As novas funcionalidades de manipulação de arquivos Office Word visa facilitar a criação e edição de documentos, otimizando o tempo e experiência do usuário. Entre as principais vantagens estão:

- Criação e edição de arquivo sem a necessidades de ter os pacotes Office Word instalados no computador do usuário;
- Transferência automatizada de informações do sistema para os documentos, evitando assim o processo de Copiar e Colar dados e eliminando os possíveis erros decorrentes dessas operações;
- Exibição do conteúdo dos documentos em tela sem a necessidade de abrir o programa Office Word, economizando assim o tempo de carregamento deste programa;
- Preenchimento automatizado de documentos através da função mala direta, realizando assim a edição de lotes de documentos em poucos segundos;

## Observação:

Essas funções só possuem suporte para arquivos Word 2007 e superior.

## Abaixo segue a exemplificação da funcionalidade:

Para criar um novo arquivo Word é necessário apenas informar o local onde o arquivo será salvo e o nome do arquivo com a extensão (.docx preferencialmente).

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/CriarArquivoWord.png)

Para abrir um arquivo Word é necessário informar o endereço do arquivo e o nome do arquivo com a extensão. Essa função irá retornar a referência do arquivo, que é necessaria para manipular e salvar o documento.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/AbrirArquivoWord.png)

Para criar um parágrafo no arquivo Word é necessário informar a referência do arquivo e o texto do parágrafo que se deseja inserir. Essa função irá criar um parágrafo com o texto passado sem formatação.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/CriarParagrafoWord.png)

Para ler os dados do arquivo Word é necessário informar a referência do arquivo que se deseja ler os dados. Essa função irá retornar os dados como Letras. Através dessa funcionalidade é possível obter também um trecho do texto informando o número do parágrafo.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/LerDadosWord.png)

Para criar uma tabela no arquivo Word é necessário informar a referência do arquivo e a tabela que se deseja inserir como uma lista de listas. A função irá criar uma tabela no arquivo sem formatação.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/CriarTabelaWord.png)

Para ler os dados de uma tabela no arquivo Word é necessário informar a referência do arquivo que se deseja ler os dados. Através dessa funcionalidade é possível obter os dados de uma linha, uma coluna coluna, ou uma determinada Tabela do arquivo (se houver mais de uma).

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/LerDadosTabelaWord.png)

A função Word - Mala Direta permite editar um arquivo Word em poucos segundos. Para isto é necessário apenas informar os endereço do arquivo modelo, o endereço do arquivo de saída e uma lista de lista com os dados do arquivo modelo que serão alterados e os novos valores que eles irão assumir no arquivo de saída.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/MalaDiretaWord.png)

Para salvar as alterações realizadas no arquivo Word após as operações Word - Criar Parágrafo, Word - Criar Tabela é necessário utilizar a função Word - Salvar Arquivo. É necessário informar a referência do arquivo Word.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/SalvarArquivoWord.png)
