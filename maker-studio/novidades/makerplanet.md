O Maker 3.9.1 traz mais uma novidade que é a Integração com a API da MakerPlanet através do plug-in disponível na IDE. É importante observar que as API's da MakerPlanet são extensões de terceiros com custos adicionais determinados pelo fabricante

O acesso a API é realizado através do menu Plugins -> MakerPlanet API
