# Novas Teclas de Atalho

Com a versão 3.9.1, o Maker traz novas teclas de atalho que facilitam o uso no editor de formulário, ao pressionar a tecla **F4** o foco será direcionado para o Inspetor de Objetos, caso seja pressionada a tecla **F11** o foco será direcionado para a Paleta de Componentes.
