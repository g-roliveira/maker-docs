A partir da versão 3.7.2.7, o desenvolvedor Maker terá acesso aos principais links para o fórum, portal do suporte, Manual do Maker 3 e a base de conhecimento.

Desta forma, diversos conteúdos poderão ser acessado para ajudar no esclarecimento de dúvidas e desenvolvimento de rotinas

Veja como funciona:
Ao abrir o Maker 3.7.2.7, o Maker trará para você a seguinte tela:

![Tela inicial](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/telainicial.png)

Observe os destaques em amarelo acima.
Caso precise de ajuda, utilize os links disponíveis para acessar ao conteúdo desejado.

Para visualizar a lista de projetos novamente, clique no botão "Posso ajudá-lo?". Conforme imagem abaixo

![Tela Projetos](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/telaprojetos.png)
