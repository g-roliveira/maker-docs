# Menu - Definir Permissão

A função "Menu - Definir Permissão" permite que permissões sejam atribuídas ao componente menu em tempo de execução

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu1.png)

No primeiro parâmetro deve ser passado o componente menu que está no formulário de trabalho selecionado no início do fluxo.

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu2.png)

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu3.png)

No segundo parâmetro deve ser passado a lista de itens que existem no Menu, obtendo-os através do xml do menu, que se encontra no componente menu no botão

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu4.png) na estrutura do menu.

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu5.png)

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu6.png)

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu7.png)

Depois de obter os "MENU CODE" o desenvolvedor deve passar por meio da função "Criar lista apartir dos Elementos" .

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu8.png)

No terceiro e no quarto parâmetro deve-se passar o valor lógico se o desenvolvedor quer deixar o componente visível ou habilitado, dependendo da lógica implementada no fluxo.

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/menu9.png)
