# Nova propriedade para o componente aba.

## Separar formulário

Quando essa propriedade é definida com valor "sim", o usuário tem a possibilidade de separar o formulário que se encontra aberto dentro de um componente aba.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/aba.png)

No Webrun o usuário pode visualizar essa funcionalidade clicando no ícone ![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/novidades/imagemnovos/restaurarTamanho.png).
