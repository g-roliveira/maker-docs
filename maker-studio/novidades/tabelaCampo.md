# Nova Propriedade "Campo" para coluna do cabeçalho - Componente Tabela

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/tabelacampo.png)

A partir da versão 3.8.1.20, cada item do cabeçalho do componente Tabela deverá estar associado à propriedade campo. Esta mudança é necessária para que a ordem das colunas no SELECT não influencie nas colunas do cabeçalho.
