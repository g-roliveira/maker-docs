# Versões Homologadas:

### Banco de dados:

- [PostgreSQL 8.2.5/8.3/8.4/9.0/9.1/9.2/9.5](recursos_avancados/suporte_banco_de_dados/postgresql)
- [Mysql 5.0/5.1/5.5/5.6](recursos_avancados/suporte_banco_de_dados/mysql_server)
- [DB2 9.5](dicas_e_truques/banco_de_dados/db2/utilizando_db2_no_maker)
- [Firebird 2.0/2.1/2.5](dicas_e_truques/banco_de_dados/firebird/utilizando_o_firebird)
- [Oracle 9i/10g/11g/12c](recursos_avancados/suporte_banco_de_dados/oracle)
- [MS SQL Server 2005/2008/2008R2/2012/2014](recursos_avancados/suporte_banco_de_dados/ms_sql_server)

### Navegador:

- Google Chrome (em suas versões mais atuais).
- Mozilla Firefox (em suas versões mais atuais).
- Internet Explorer (em suas versões mais atuais)

### Sistema Operacional:

- Windows 7, 8.0, 8.1, 10 (Para Maker e Webrun).
- Windows Server 2008, 2003, 2012 (Somente Webrun).
- Linux (Somente Webrun). Exemplos: Ubuntu, Red Hat, Slackware, Debian, SuSE, Fedora, Mandriva, entre outros....

### Servidor de Aplicação:

- JBoss-4.2.1GA.
- Webshere Application Server (6.1 e 7 e 8.5 em Fase de Homologação) .
- Tomcat6 , Tomcat7 e a partir da versão Maker Studio, Tomcat 8.5.
- IIS 6.0 , 7.5 e 8.5.
- Dot.Net Framework 4.0 (A partir do Maker 3.6) e 2.0 (Versões inferiores do Maker 3.5).

### JDK:

- JDK6 (1.6)
- JDK7 (1.7).
- JDK8 (1.8) para versões Maker Studio ou superiores.
