Causa: Ao tentar utilizar o [Identificador Biométrico](../../maker_3/instalacoes/como_instalar_o_servidor_biometrico) no mesmo browser para mais de um sistema que estejam abertos.

Solução: Para que funcione corretamente, é necessário reiniciar o browser antes de acessar novamente o applet do outro sistema.
