Este tópico tem como objetivo demonstrar melhores práticas de desenvolvimento com fluxogramas, com intuito de melhorar o seu entendimento, evitar problemas de escalabilidade, legibilidade, suporte futuro ao sistema, erros de compilação e etc. Não há nenhuma pretensão de se construir um guia no estilo "how to" visto a flexibilidade de programar em fluxos, as diferentes necessidades de uma regra de negócio e os diferentes padrões de projeto que os desenvolvedores podem adotar. Abaixo, constam os subtópicos relacionados a este guia.

- [Organização de fluxos através de subfluxos](organizacao_de_fluxos_atraves_de_subfluxos)
- [Melhorando o aspecto visual de um fluxo utilizando o objeto comentário](melhorando_o_aspecto_visual_de_um_fluxo_utilizando_o_objeto_comentario)
- [Descrevendo os objetos do fluxo](descrevendo_os_objetos_do_fluxo)
- [Melhorar desempenho na execução de regras](melhorar_desempenho_na_execucao_de_regras)
