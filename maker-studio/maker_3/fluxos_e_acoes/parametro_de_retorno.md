# Parâmetro de Retorno

O parâmetro de retorno é um valor ou [Identificador (variável)](exibir) que, depois de executada toda ação do fluxo, será passado como parâmetro de requisição. Geralmente este parâmetro é utilizado dentro de um subfluxo, o qual retorna o valor para dar continuidade à ação. Esta opção é também muito utilizada para dar um valor padrão (default) a algum campo do formulário.

Execute clique duplo sobre o objeto ![fim](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image334.png) e a tela Parâmetro de Retorno é exibida:

![image122.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image333.png)

A tela possui os campos:

- Tipo do retorno - é o tipo do Identificador (variável) que será retornado;
- Tamanho - geralmente utilizado quando se atribui o tipo Letras e serve para limitar o tamanho do Identificador (variável);
- Valor de retorno - é o valor ou indicação do Identificador (variável) que será retornado pelo fluxo de ações.

Observações:

1. O fluxo cliente não retorna para servidor.
2. Para deletar um objeto informado no valor de retorno, deve-se usar a combinação de teclas Ctrl+Delete.
