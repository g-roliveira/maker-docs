O Otimizador de Consultas verifica as consultas (fontes de dados da Conexão Principal e de Conexões Adicionais) associadas a formulários e componentes, Caixas de seleção por exemplo, objetivando melhor performance da estrutura de seleção.

Para acessar este recurso, ative o menu Utilitários e clique em Otimizador de consultas...:

![image211.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image667.png)

A tela é composta apenas por duas opções fundamentais:

- ![image459.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image668.png) - para checar todos os comandos SQL relacionados com o projeto;
- Botão ![image460.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image669.png) - inicia o processo de otimização.

Após clicar no botão ![image461.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image669.png), encontrando inconformidades, as consultas serão sinalizadas em vermelho.

Para ajustes, selecione a consulta executando clique duplo sobre o nome. A tela Erro de SQL: &lt;nome do objeto&gt; é acionada:

![image212.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image670.png)

O usuário que estiver analisando o problema detectado poderá resolver de dois modos: utilizando o botão ![image213.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image671.png) para que o Maker corrija automaticamente ou manualmente por meio do ![image462.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image672.png).
