- Alinha à direita - alinha todos os componentes à direita, tomando por base, dentre o conjunto de componentes selecionados, o que estava mais à direita.
- Alinha no topo - alinha todos os componentes, tomando por base, dentre o conjunto de componentes selecionados, o que estava mais próximo da parte superior do formulário.
- Alinha na base - alinha todos os componentes, tomando por base, dentre o conjunto de componentes selecionados, o que estava mais próximo da parte inferior do formulário.
- Exibir barra de ferramentas - clicando sobre esta opção, aparece a tela Alinhamento, na qual são disponibilizadas mais opções de alinhamento.

![image143.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image184.png)

As opções de alinhamento da imagem acima, possuem as seguintes funções:

- ![image144.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image185.png) - dispõe os componentes selecionados à posição mais à esquerda entre eles;
- ![image145.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image186.png) - dispõe os componentes selecionados à posição centralizada horizontalmente entre eles;
- ![image146.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/meio.png) - dispõe os componentes selecionados à posição centralizada horizontalmente da largura do formulário;
- ![image147.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/lado.png) - Iguala o espaçamento horizontal dos componentes selecionados;
- ![image148.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image189.png)  - dispõe os componentes selecionados à posição mais à direita entre eles;
- ![image149.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image190.png) - dispõe os componentes selecionados à posição mais acima entre eles;
- ![image150.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image191.png) - dispõe os componentes selecionados à posição centralizada verticalmente entre eles;
- ![image151.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image192.png) - dispõe os componentes selecionados à posição centralizada verticalmente da largura do formulário;
- ![image152.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image193.png) - Iguala o espaçamento vertical dos componentes selecionados;
- ![image153.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image194.png) - dispõe os componentes selecionados à posição mais abaixo entre eles.
