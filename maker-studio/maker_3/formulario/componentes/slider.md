## Slider

O ***componente Slider*** permite que o  usuário selecione um valor, e ao deslizar o botão este valor será modificado aonde ele desejar.

![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image3.png)

Propriedades: Comuns de todos os componentes: Posição X; Posição Y; Altura; Tamanho; Visível; Habilitado; Nome; Código; Ordem

Barra secundária com cores alteráveis no CSS

**Propriedades do Componente**

O componente Slider  possui suas propriedades específicas, são elas:

**Propriedade Imagem do seletor / Imagem do seletor URL / Valor Início / Valor Final / Casas Decimais / Valor Inicial do marcador / Exibir Numeração**

![image4.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image4.png)
