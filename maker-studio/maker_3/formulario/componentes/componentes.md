Os componentes são elementos que irão compor um formulário. Todos os componentes disponibilizados pelo Maker apresentam-se apenas no modo de edição de formulário.

![image49.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image144.png)

A descrição de cada componente é:

- [Caixa de Texto](caixa_de_texto) - componente que permite a edição de dados;
- [Texto](texto) - componente que pode ser utilizado para dar nomes a outros componentes (Label);
- [Check](check) - componente que permite marcar ou desmarcar valores dentro de um formulário (no caso de estar marcado, será armazenado o valor verdadeiro no banco de dados);
- [Lista Dinâmica](lista_dinamica) - componente que permite a definição de uma lista dinâmica de valores dentro do formulário, conhecido como Lookup;
- [Gráfico](grafico) - componente que permite desenvolver um gráfico vinculado ao formulário;
- [Botão](botao) - componente que permite fazer a chamada a outros formulários e executar fluxos com um clique;
- [Imagem](imagem) - componente que permite utilizar imagens dentro do formulário;
- [Moldura](moldura) - componente que permite agrupar outros componentes dentro de um Frame (Moldura Abaixada ou Levantada);
- [Lista](lista) - componente para se definir uma lista estática (valores fixos);
- [Lista Dupla](lista_dupla) - componente utilizado para que uma lista alimente outra lista. O relacionamento está definido como N:N;
- [Opções](opcoes) - componente que permite agrupar um conjunto de dados de única seleção. Permite definir uma lista de valores e sua respectiva descrição, conhecido como Radiogroup;
- [Texto Longo](texto_longo) - componente parecido como a Caixa de Texto, com a diferença que permite armazenar uma quantidade de texto maior. É conhecido como Memo;
- [Subformulário](subformulario) - componente que permite chamar outro formulário. É conhecido como DetailPanel;
- [Grade](grade) - componente que permite apresentar colunas (campos) de um formulário na aplicação. Esse componente permite também chamar outros formulários nos quais estão os campos que formam parte da Grade;
- [Árvore](arvore) - componente que permite criar uma TreeView vinculada ao formulário.
- [Tabela](tabela) - componente que permite criar uma tabela derivada de uma consulta Sql.
- [Rss](rss) - componente que permite exibir um feed de notícias no formulário.
- [Galeira de Imagens](galeria_imagens) - componente que permite criar uma galeria de imagens no formulário.
- [Gráfico Maker 3.8](graficomaker3) - componente que permite criar uma galeria de imagens no formulário.
- [Organograma](organograma) - componente que permite criar uma galeria de imagens no formulário.
- [Accordion](accordion) - componente que permite o desenvolvedor colocar resultados de consultas em forma de cascata.
- [Ação](acao) - componente que executa uma ação relacionada a uma imagem pré-definida ao clicar ou ao passar do mouse
- [Chat](Chat) - componente que cria um chat quando 2 ou mais úsuarios estão usando o mesmo sistema.
- [Player](player) - componente que permite a execução de playlists de músicas e videos no formulário.
- [Slider Painel](sliderpainel) - componente que permite criar um slide de imagens.
- [Timer](timer) - componente que permite marcar o tempo do úsuario logado no sistema ou formulário.
- [Slider](slider) - componente que permite a dosagem, o desenvolvedor pode criar diferentes tipos de logicas e implementações com esse componente.
- [Menu](menu) - componente que permite criar um menu em um formulário.
- [Calendário](calendario) - componente que marca as datas exibindo um calendário
- [Aba](aba) - componente que permite a inclusão de varios formulários em modo de aba.

Observação: Não devem ser utilizados caracteres que não fazem parte do Charset: ISO-8859-1, como por exemplo €,&,§ nos valores dos componentes.
