O Assistente de Criação de Novo Formulário tem o objetivo de criar formulários a partir de uma fonte de dados.

![image330.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image202.png)

A tela é composta pelos campos:

- Nome do Formulário - define o título do formulário;
- Conexão - é a conexão da qual será selecionada a Fonte de Dados;
- A fonte de dados (entidade) que ficará vinculada ao formulário pode ser associada por meio do campo Fonte de Dados ou por uma consulta criada pela tela [Assistente SQL](assistente_sql/iniciando_com_o_assistente_sql), clicando no botão ![assistente de consulta](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image203.png). Executada uma dessas ações, de imediato, aparece(m) o(s) campo(s) na grade Campos do Formulário;
- ![image637.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image204.png) - Mover para início - move o campo para a posição imediatamente superior à que ele estava posicionado;
- ![image638.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image205.png) - Mover acima - move o campo para a posição imediatamente superior à dele;
- ![image639.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image206.png) - Mover abaixo - move o campo para a posição imediatamente inferior à que ele estava posicionado;
- ![image640.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image207.png) - Mover para o final - move o campo para o fim da grade.

A confirmação da  criação do formulário é feita comum clique no botão OK, e o cancelamento da criação do formulário é feito com um clique no botão Cancelar.

Observações:

1. Ao tentar criar um formulário, caso o projeto utilizado contenha muitas tabelas e conexões adicionais, a abertura do Assistente de criação poderá ficar lenta.
2. Ao selecionar uma entidade no campo Fonte de Dados a mesma só poderá ser cancelada, se for selecionada outra entidade ou cancelando e criando um novo formulário.
3. Usando a combinação das teclas Alt+E, é possível Cancelar o assistente de criação de formulário;
4. Todas as etiquetas (títulos) dos componentes inseridos no formulário pelo Assistente de Criação de Novo Formulário podem ser predefinidas na tela do [Dicionário de Dados](../dicionario_de_dados/dicionario_de_dados) (serão usadas as descrições dadas aos campos de cada entidade).
5. Criando formulário pela tela Assistente de Criação de Novo Formulário e a fonte de dados possuindo mais de 3 campos, por d*efault,* são selecionados (três) campos na coluna Pesquisa e (seis) na coluna Grade.
6. O formulário será criado com duas abas: a primeira, por padrão, é chamada Cadastro; e a segunda é chamada Localizar (Para maiores explicações, ver item [Definição de Formulários](propriedade_do_formulario)):
