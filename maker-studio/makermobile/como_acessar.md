# Como acessar o Maker Mobile

A utilização do Maker Mobile é muito simples.

- Para utilizá-lo basta acessar o menu do Maker -> *Mobile* -> *Login*.

  ![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/exportacao_1_.jpg)
- Com a tela de autenticação aberta, basta preencher os campos **Usuário** e **Senha** e clicar em **Conectar**.

  ![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/exportacao_2_.jpg)

Criando uma nova conta

- Para o primeiro acesso, é necessário que o usuário seja cadastrado. Utilize a opção *Cadastre-se* da tela de Login para acessar esta tela.

  ![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/exportacao_3_.jpg)
- Preencha todos os dados e clique em **Próximo**. Na próxima tela, preencha os dados solicitados.

  ![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/exportacao_4_.jpg)
  > Caso as informações estejam corretas e a chave de licença tenha acesso ao Maker Mobile, o login será feito automaticamente no ambiente mobile.
- Caso a autenticação seja realizada com sucesso, os menus [Exportar para plataforma](como_exportar), [Lista de projetos em compilação](lista_exportacao), [Comprar Créditos](comprando_creditos_para_exportacao_de_projetos) e **Histórico de compras** serão habilitados e os recursos e propriedades suportadas pelo Mobile estarão destacados.

  ![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/exportacao_5_.jpg)
  ![](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/exportacao_6_.jpg)

  Observe que um ícone de um aparelho mobile aparecerá nas propriedades de componentes e em funções que forem compatíveis com o Maker Mobile.
