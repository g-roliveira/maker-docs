# Primeiros passos para criar uma app no Facebook e utilizá-la no Maker

**Tutorial**:

**Como posso obter o APP ID para utilizar no meu aplicativo?**

**Obtendo APP ID**

O foco deste tutorial é explicar a criação de um aplicativo no Facebook e utilizá-lo com as funções do Maker.

1. O primeiro passo é  [criar um App](https://developers.facebook.com/) e clicar em "Create a New App" que aparecerá na barra superior da página como mostra a imagem abaixo:

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/redessociais/facebook/apiFb/form_18.png)

2. Aparecerá uma janela poup-up, para que o usuário possa preencher campos necessários para descrição do app

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/redessociais/facebook/apiFb/form_21.png)

3. Após preencher os campos, o próximo passo é configurar o App na nova tela que irá surgir:

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/redessociais/facebook/apiFb/form_19.png)

4. Clicar em **"Settings"** no menu a esquerda, é importante anotar os números que aparecem no campo "App ID", ele será utilizado na configuração de algumas funções.

5. O campo **"Contact Email"** deverá obrigatoriamente ser preenchido com um e-mail para contato caso o aplicativo seja liberado para uso público (veremos isso a seguir).

6. Para configurar o uso do aplicativo em um novo website é preciso clicar no botão  **"+ Add Platform"** selecionando **"Website"**, aparecerão os campos logo acima do botão, o **"Site URL"** deverá especificar em qual domínio está sendo utilizado esse App.

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/redessociais/facebook/apiFb/form_22.png)

7. Clicando em **"Status e Review"** aparecerá seguinte tela:

![Imagem do manual](https://suporte.softwell.com.br/Manual/MakerStudio/redessociais/facebook/apiFb/form_20.png)

Para que o App funcione para todos os usuários que possuem conta no Facebook, é preciso clicar no botão em destaque na imagem acima, ele inicialmente estará como **"No"** uma mensagem aparecerá solicitando confirmação antes de alterar.
Feito isso, o aplicativo do Facebook estará configurado para uso no Maker.
Depois será possível utilizar quaisquer outras funções do Facebook.
