Aqui se definem parâmetros para configurar o AutoCarregar dos sistemas.

![AutoCarregar](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1503.png)

Na tela Parâmetros de Configuração, ao clicar em ![image1869.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1869.png), mostra os componentes:

- ![image598.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image598.png) - permite criar um novo parâmetro para o grupo;
- ![image597.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image597.png) - permite excluir o parâmetro e seus valores. O controle de check ao lado de cada parâmetro será utilizado para esse fim;
- ![image599.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image599.png) - Permite excluir um valor do parâmetro. podem existir muitos valores para cada parâmetro;
- ![image600.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image600.png) - Permite adicionar um novo valor ao parâmetro. podem existir muitos valores para cada parâmetro.

Abaixo, verifique o principal parâmetro para o grupo AutoCarregar:

- Sistemas - Carrega automaticamente um sistema durante a carga inicial do servidor de aplicações. Melhorando assim seu desempenho ao carregar pela primeira vez

Observações:

1. Para adicionar o parâmetro siga os passos abaixo:
   1. Acesse as configurações do Webrun;
   2. Clique em Parâmetros Avançados;
   3. Crie um novo Grupo com o nome AutoCarregar;
   4. Crie um novo parâmetro com o nome Sistemas;
   5. Atribua a sigla do sistema como valor do parâmetro criado anteriormente.

2. Só é permitido um sistema por parâmetro.
