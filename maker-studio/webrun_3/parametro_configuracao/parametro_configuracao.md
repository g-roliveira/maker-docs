Em Parâmetros de Configurações, o usuário avançado poderá determinar configurações gerais para a execução de todos os sistemas no Webrun.

Para acessar e editar as configurações, siga os passos:

1. [Acesse o Webrun](../acessando_webrun);
2. Acesse a tela Sistemas e clique em ![image499.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image499.png). Informe Usuário = admin e Senha = webrun e clique em ![image501.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image501.png);
3. Na tela "Tela de Configuração", clique em ![image593.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image593.png).

![image1838.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1838.jpg)

4. Na imagem abaixo, observe que as configurações estão agrupadas numa lista e, quando clicar no link, serão exibidos os parâmetros. Os grupos exibidos abaixo são padrões, quando instalado o WebRun.

![image281.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image281.jpg)

Observe os seguintes componentes da tela:

- ![image282.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image282.jpg) - Após informar todas as configurações necessárias, deve-se salvar;
- ![image283.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image283.jpg) - Sai da tela de Parâmetros de Configuração;
- ![image594.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image594.png) - Permite criar um novo grupo de parâmetros;
- ![image595.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image595.png) - Permite excluir um grupo de parâmetros. O controle de check ao lado de cada grupo será utilizado para este fim.

São grupos que podem ser definidos na tela Parâmetros de Configuração (Configuração do Sistema):

- [Agendador](parametros_configuracao_agendador)
- [AutoCarregar](parametros_de_configuracao_autocarregar)
- [Componentes](parametros_configuracao_componentes)
- [Proxy](parametros_configuracao_proxy)
- [Relatorio](parametros_configuracao_relatorio)
- [Sessao](parametros_configuracao_sessao)
- [ServidorDigital](parametros_de_configuracao_servidor_digital)
- [Seguranca](parametros_de_configuracao_seguranca)
