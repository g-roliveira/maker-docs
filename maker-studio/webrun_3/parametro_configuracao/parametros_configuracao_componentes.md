Aqui se definem parâmetros para configurar componentes de formulários:

![image286.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image286.jpg)

Na tela Parâmetros de Configuração, ao clicar no componente ![image602.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image602.png), mostra os componentes:

- ![image598.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image598.png) - permite criar um novo parâmetro para o grupo;
- ![image597.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image597.png) - permite excluir o parâmetro e seus valores. O controle de check ao lado de cada parâmetro será utilizado para esse fim;
- ![image599.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image599.png) - Permite excluir um valor do parâmetro. podem existir muitos valores para cada parâmetro;
- ![image600.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image600.png) - Permite adicionar um novo valor ao parâmetro. podem existir muitos valores para cada parâmetro.

Abaixo, verifique os principais parâmetros para o grupo Componentes:

- CarregarMoreLookup - define se os componentes Lista serão ou não utilizados. Valor-padrão 1 (ativados);
- PaginacaoConsulta - define a quantidade de itens na exibição do conteúdo da lista, na aba localizar;
- PaginacaoGrid - define a quantidade de itens na exibição do componente Grade;
- PaginacaoMoreLookup - define a quantidade de itens na exibição do componente Lista.
