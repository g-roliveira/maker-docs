Acesse uma série de Configurações do Webrun pelo botão ![image499.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image499.png):

![image1823.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1823.jpg)

A Tela de Configuração possui as seguintes opções:

- Botão ![image568.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image568.png) - este botão atualiza a lista de projetos (mais detalhes no tópico Atualizando a lista de sistemas do Webrun);
- Botão  ![image569.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image569.png) - acessa a tela Configuração do Sistema. Para mais informações, acesse o tópico Módulo de Configurações;
- Botão ![image570.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image570.png) -  este botão, ao clicar ele irá direcioná-lo para uma tela aonde será possível modificar a senha para ter acesso à "Tela de Configuração";
- Botão ![image571.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image571.png) -  exibe a lista de sistemas que podem ser gerenciados (adicionar novo sistema na lista, excluir ou mesmo recarregar). Para mais informações, acesse o tópico Gerenciando Sistemas no Webrun;
- Botão ![image572.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image572.png) - Em Parâmetros de Configurações, o usuário avançado poderá determinar configurações gerais para a execução de todos os sistemas no Webrun. Para mais informações, acesse o tópico Parâmetros de Configuração.

## Suporte a alteração de senha administrativa

A partir da versão 3 do Webrun, foi adicionado uma nova funcionalidade que permite ao usuário alterar a senha administrativa, através da tela de configuração.

![image1822.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1822.jpg)

Observação: Após utilização do assistente, a senha será armazenada criptografada e versões anteriores á 3 não acessarão com a senha normal, sendo necessário informar o hash MD5 gerado.

## Tela de Configuração Avançada

Após ter clicado em ![image569.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image569.png) e ao clicar no link "Configuração Avançada" na tela "Configuração do sistema - &lt;Sigla do Sistema&gt;" será aberto mostrando de imediato os parâmetros utilizados pela "Conexão Principal". Na mesma tela consta:

![image265.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image265.jpg)

- O botão ![image573.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image573.gif) - é utilizado para a criação de um novo parâmetro para a conexão que estiver selecionada. Ao ser selecionado, abrirá a tela Prompt do usuário do Explorer:

![image266.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image266.jpg)

- O botão ![image574.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image574.gif) - clicando sobre este link, será apresentada uma caixa de seleção onde é possível selecionar a configuração que se quer modificar:

![image575.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image575.gif)

- O botão ![image576.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image576.png) - exclui o parâmetro;
- O botão ![image577.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image577.png) - clicando neste botão, todas as modificações efetuadas na conexão que estavam selecionadas serão confirmadas (gravadas) e a tela "Configuração do sistema - &lt;Sigla do Sistema&gt;" se fechará. Ademais, aparecerá, em seguida, uma mensagem de alerta que solicita o reinício do sistema; assim todas as alterações feitas na configuração serão observadas:

![image267.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image267.jpg)
