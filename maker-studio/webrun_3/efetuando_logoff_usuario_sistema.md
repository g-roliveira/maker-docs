Este recurso está habilitado para todos os usuários e permite que seja executado um logoff do sistema para a entrada de outra identificação de usuário.

Para acessar este recurso, siga os passos:

![image1828.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1828.jpg)

1. Informe o nome e a senha do usuário;
2. Clique em ![image501.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image501.png).

Observações:

1. O botão ![image533.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image533.png) - retorna para a tela Sistemas, onde é possível selecionar um projeto.
