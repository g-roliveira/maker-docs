O acesso a um sistema no Webrun pode ser feito por um administrador ou por um simples usuário. O contexto, então, será reestruturado para cada perfil. O contexto deste exemplo de documento seguirá a exibição para um usuário com perfil administrador. Observe a tela abaixo:

![image1830.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1830.jpg)

A área de trabalho é composta pelos seguintes componentes:

## Barra de Menus do sistema em uso

Acesse os formulários e relatórios com um clique no mouse sobre os menus do sistema.

## Ícones de Gerenciamento do sistema

Esses ícones permitirão executar as seguintes tarefas:

- ![image512.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image512.png) Grupos - permite gerenciar os grupos de usuários que terão acesso ao sistema em uso. Para mais informações, acesse o tópico Gerenciando Grupos de Usuário de um sistema no Webrun;
- ![image513.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image513.png) Usuários - permite gerenciar os usuários que terão acesso ao sistema em uso. Para mais informações, acesse o tópico Gerenciando Usuário de um sistema no Webrun;
- ![image515.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image515.png) Alterar Senha - permite a modificação da senha master. Para mais detalhes, acesse o tópico Mudando a senha master;
- ![image518.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image518.png) Executor Script SQL - executa arquivo de script de banco (inserção, atualização, recuperação e remoção de registro);
- ![image519.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image519.png) Recarregar Sistema - atualiza todo o sistema;
- ![image520.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image520.png) Configurar Conexões Adicionais - configura as conexões adicionadas do projeto.

## Barra de Controle do Webrun

- Esta barra está composta por botões com as seguintes funções:
- ![image522.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image522.png) - ativa o Modo Gerente para controle dos acessos aos formulários, componentes e relatórios do sistema. Obtenha mais informações pelo tópico [Trabalhando no Modo Gerente](trabalhando_modo_gerente_);
- ![image523.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image523.png) - ativa o modo de projeto para executar modificações no sistema pelo Webrun. Obtenha mais informações no tópico Trabalhando no Modo de Projeto;
- ![image524.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image524.png) - atualiza os objetos da Barra de Menus do Sistema;
- ![image525.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image525.png) - sai do Modo Gerente ou do Modo Projeto;
- ![image526.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image526.png) - ative esta opção para mudar a identificação do usuário atual;
- ![image527.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image527.png) - sai do sistema, retornando à tela de Sistemas.

Observação: Para usuários que não tenham perfís de Gerente ou Administrador do projeto, estariam disponíveis na tela apenas os menus e objetos configurados ao perfil e os comandos de: Alterar a Senha, Trocar Usuário e Sair.
