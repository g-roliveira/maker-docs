Após ter acessado a tela Tela de Configuração, é apresentada a tela Configuração do Sistema &lt;sigla do sistema&gt;:

![image1826.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1826.jpg)

A tela é composta pelas seguintes opções:

- Campo Instância - apresenta o nome da instância definida para o sistema. Essa informação pode ser complementada pelo tópico [Configurações](../maker_3/configuracao_das_conexoes/configuracoes);
- Campo Servidor - apresenta o nome do servidor de acesso onde a base de dados do projeto selecionado está armazenada;
- Campo Banco - informa o nome do banco de dados do projeto selecionado;
- Campo Usuário - informa o nome do usuário master de acesso ao banco de dados do projeto selecionado;
- Campo Senha - informa a senha do usuário master de acesso ao banco de dados do projeto selecionado;
- Botão ![image578.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image578.png) - retorna à [Tela de Configuração](tela_configuracoes);

- Botão ![image579.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image579.png) - este recurso permite a [Geração do Código-Fonte](../recursos_avancados/geracao_codigo_fonte/geracao_codigo_fonte) de um projeto;
- Botão ![image580.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image580.png) - reinicia o serviço de acesso e processos do projeto selecionado;
- Botão ![imagemg.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/imagemg.png) - executa atualização das modificações que ocorram nos campos da tela.
