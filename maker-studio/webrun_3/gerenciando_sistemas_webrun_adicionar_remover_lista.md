Verifique os projetos que estão sendo executados no servidor de aplicações pelo Webrun.

1. Após acessar a [Tela de Configuração](tela_configuracoes), clique no botão ![image581.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image581.png);

![image1839.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image1839.jpg)

É exibida a tela:

![image273.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image273.jpg)

A tela Adicionar / Remover WFRE exibe a lista de sistemas que podem ser gerenciados. A tela possui os seguintes componentes:

1. Pelo botão ![image582.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image582.png) permite informar o arquivo através do diretório.
2. Botão ![image583.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image583.png) - adiciona o projeto indicado no campo Arquivo, na relação de sistemas.
3. Botão ![image584.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image584.png) - atualiza toda a lista de sistemas.
4. Botão ![image585.png](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image585.png) - ao lado de cada sistema, permite excluir da relação.
