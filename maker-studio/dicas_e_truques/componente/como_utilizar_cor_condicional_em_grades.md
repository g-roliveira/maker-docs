Os passos a seguir ajudarão a utilizar o recurso de Cor Condicional no componente Grade.

1. Desenvolva um formulário e insira um componente [Grade](../../maker_3/formulario/componentes/grade).
2. Clique no componente com o botão direito do mouse e defina as [Propriedades](../../maker_3/formulario/propriedades_e_eventos) básicas (Formulário, SubFormulário, Parâmetros e Colunas).
3. Ainda em Propriedades, clique no botão ![image633.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image633.jpg) (construtor) ao lado da propriedade [CorCondicional](../../maker_3/formulario/propriedades_e_eventos). É exibida a tela Editor condicional de cores para grade:

![image416.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image416.jpg)

A tela é composta, simplesmente, por duas áreas: Condição (que define o critério e a cor) e Campo (define o(s) campo(s) para receberem a formatação).

Execute clique duplo no campo Condição para ativar a tela Montador de Expressões para criar o critério da formatação.

Para visualizar a tela Montador de Expressões, .

4. Após definir a expressão condicional e sair da tela Montador de Expressões, selecione a Cor executando clique duplo no próprio campo Cor.
5. Por fim, selecione o(s) campo(s) para serem formatados. Utilize o botão ![image662.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image662.gif) (Novo) ou ![image663.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image663.gif) (teclado). Utilize o botão ![image664.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/image644.jpg) (salvar) para gravar.

Observações:

1. Os campos que fornecem o valor para a condição são campos com componentes do tipo [Caixa de Texto](../../maker_3/formulario/componentes/caixa_de_texto) ou [Lista](../../maker_3/formulario/componentes/lista) (com campo chave e lista iguais).
2. Campos somente leitura não receberão a cor condicional.
