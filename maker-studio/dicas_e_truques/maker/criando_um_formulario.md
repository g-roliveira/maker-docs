Para criar um formulário o usuário irá na tela de propriedades do sistema do Maker, clique no botão ![image95.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form1.png).

Executada a ação acima, aparecerá a tela Assistente de Criação de Novo Formulário:

![image495.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form2.png)

Nesta tela, deve-se inserir:

- o nome (título) do formulário, no campo Nome do Formulário;
- a conexão da qual será selecionada a Fonte de Dados e criada a consulta (botão ![image692.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form3.png)), no campo [Conexão](../../maker_3/configuracao_das_conexoes/conexoes_adicionais);
- a fonte de dados (entidade) que ficará vinculada ao formulário, no campo Fonte de Dados, ou a consulta criada pela tela [Assistente SQL](../../maker_3/formulario/assistente_sql/iniciando_com_o_assistente_sql), clicando no botão ![image692.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form3.png). Executada uma dessas ações, de imediato, aparece(m) o(s) campo(s) na grade Campos do Formulário.

Observações:

1. Todas as etiquetas (títulos) dos componentes inseridos no formulário pelo Assistente de Criação de Novo Formulário podem ser predefinidas na tela do Dicionário de Dados (serão usadas as descrições dadas aos campos de cada entidade);
2. O formulário será criado com duas abas: a primeira, por padrão, é chamada Cadastro, e a segunda é chamada Localizar (Para maiores explicações, ver item Definição de Formulários).

Para confirmar a criação do formulário, clique no botão OK, caso contrário, clique em Cancelar.

Clique no botão ![image692.gif](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form3.png) para abrir a tela [Assistente SQL](../../maker_3/formulario/assistente_sql/iniciando_com_o_assistente_sql).

![image1241.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form4.png)

Pela tela Assistente SQL, será criada a consulta que comporá o formulário. Caso tenha sido selecionada mais de uma entidade na área do Assistente SQL, os dados que serão informados no formulário, quando utilizados no Webrun só poderão ser gravados na primeira entidade selecionada.

Para confirmar as alterações, clique no botão OK, caso contrário, clique em Cancelar.

O formulário ficará da seguinte forma:

![image497.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form5.png)

![image498.jpg](https://suporte.softwell.com.br/Manual/MakerStudio/imagens/form6.png)

Observação: Após a criação do formulário, não é possível alterar a descrição do campo automaticamente. Caso o campo do formulário seja modificado, é necessário que manualmente, seja alterado.
