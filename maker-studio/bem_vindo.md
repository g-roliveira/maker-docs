# Manual do Maker Studio

# Bem Vindo!

Esse Help on-line tem por objetivo apresentar todos os recursos do Maker a partir da versão: **3**.

O usuário pode comparar os recursos disponíveis em cada versão do Maker utilizando o tópico [Recursos e Características das Versões do Maker](recursos_e_caracteristicas_das_versoes_do_maker). Com uma abordagem de fácil leitura, objetiva e composta por exemplos, conheça todo o potencial que a ferramenta oferece. Saiba um pouco mais sobre a empresa acessando o tópico [Softwell Solutions](softwell_solutions) ou o site &lt;http://www.softwell.com.br&gt;.

Faça um [Tour no Maker](tour) para conhecer os recursos que o Maker proporciona. Para usuários que já trabalham com o Maker, consulte o tópico [O que há de novo!](whatisnew) e verifique os novos itens e implementações no Help.

Para usuários avançados, acesse o tópico [Recursos Avançados](recursos_avancados/recursos_avancados) ou [Dicas e Truques](dicas_e_truques/dicas_e_truques). Conheça as perguntas mais frequentes sobre o Maker acessando o tópico [F.A.Q. - Frequently Asked Questions Maker](faq/F.A.Q._-_Frequently_Asked_Questions_Maker).

Para executar o **download** do Help do Maker (**desktop**), [clique aqui](http://suporte.softwell.com.br/maker/manual2_6/pt/maker2.zip) e **descompacte** na pasta **C:\Arquivos de programas\Softwell Solutions\Maker 3**.

IMPORTANTE:

O Maker foi concebido para ser utilizado por profissionais, portanto o desenvolvedor deve ter conhecimento de lógica de programação e modelagem de banco de dados relacional.

**Bom Trabalho!**
