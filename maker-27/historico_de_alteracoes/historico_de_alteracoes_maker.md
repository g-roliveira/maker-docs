## **Maker 2.7.0.0**

**Histórico de modificações:**

- Disponível o sistema **[Maker Mobile Manager](http://mobile.softwell.com.br/manual/como_sicronizar.html)** que possibilitará a sincronização de dados com dispositivos móveis.
- A instalação do Maker 2.7 inclui o PostgreSQL 9.0.
- Melhoria na geração do XML de fluxos, evitando erros *code too large* provocados por fluxos com muitos IFs encadeados.
- Nova área de configuração (Maker2.ini) no Maker 2.7, possibilitando utilização do Maker 2.6 e 2.7 simultaneamente.
- Duas novas comunidades: [Fórum Maker Portal](http://forum.makerportal.com.br/) e [Maker Tips](http://makertips.wordpress.com/) disponíveis no menu **Comunidades** do Maker.

- Desenvolvimento para dispositivos móveis - Nesta nova versão do Maker, é possível desenvolver para dispositivos móveis contando com a facilidade proporcionada pelo Maker.
- Sincronizador de dados automático - O Maker Mobile, possui um sincronizador de dados responsável por manter as tabelas do servidor em constante atualização com o dispositivo cliente, sem a necessidade de outra implementação.
- Novos servidores de bancos de dados:

- MySQL 5.0, 5.1 e 5.5;
- PostgreSQL 8.2.5, 8.3*, 8.4, 9.0;
- Firebird 2.0 e 2.5;
- SQL Server 2005, 2008 e 2008 R2;
- Oracle 9i / 10g / 11g.

* Veja as limitações do PostgreSQL 8.3 clicando

- Novos navegadores (browsers)

- Firefox 2.0*, 3.6, 4.0 e 6.0;
- Internet Explorer 6.0*, 7.0, 8.0 e 9.0;

** O Google Chrome está em fase de homologação e estará disponível em breve.
