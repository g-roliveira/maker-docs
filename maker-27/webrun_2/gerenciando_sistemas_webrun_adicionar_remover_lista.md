Verifique os projetos que estão sendo executados no servidor de aplicações pelo Webrun.

1. Após acessar a [Tela de Configuração](tela_configuracoes), clique no botão ![image581.gif](../image581.gif);

![image1839.jpg](../image1839.jpg)

É exibida a tela:

![image273.jpg](../image273.jpg)

A tela Adicionar / Remover WFRE exibe a lista de sistemas que podem ser gerenciados. A tela possui os seguintes componentes:

1. Campo Arquivo - permite informar o arquivo. Pelo botão ![image582.gif](../image582.gif) ativa-se a tela Enviar arquivo para auxiliar a localização.
2. Botão ![image583.gif](../image583.gif) - adiciona o projeto indicado no campo Arquivo, na relação de sistemas.
3. Botão ![image584.gif](../image584.gif) - atualiza toda a lista de sistemas.
4. Botão ![image585.gif](../image585.gif) - ao lado de cada sistema, permite excluir da relação.
