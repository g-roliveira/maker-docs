Após Acessar um sistema no Webrun, na área de trabalho, o ícone ![image512.gif](../image512.gif) Grupos permitirá gerenciar os grupos de usuários para o acesso ao sistema em uso.

Executando clique duplo sobre o ícone, é exibida a tela Grupos, permitindo a edição dos grupos de usuários:

![image254.jpg](../image254.jpg)

A tela é composta pelos seguintes itens:

- Aba Cadastro:

- Campo Código do Sistema - sigla do sistema em uso;
- Campo Descrição - nome do sistema em uso;
- Botão ![image538.gif](../image538.gif) - permite incluir um novo grupo;
- Botão ![image539.gif](../image539.gif) - permite editar a descrição de um grupo selecionado;
- Botão ![image540.gif](../image540.gif) - permite excluir um grupo selecionado;
- Botão ![image541.gif](../image541.gif) - atualiza a lista de grupos.

- Barra de ferramentas da tela:
- - Botão ![image542.gif](../image542.gif) - acessa a tela de Log de edições da tela ou de todo o sistema. Para mais informações sobre *log, acesse o tópico Gerenciando Logs no Sistema;*
  - Botão ![image543.gif](../image543.gif) - permite definir valores padrão para o cadastramento de novos registros. Este item não se aplica para este cadastramento;
  - Botão ![image546.gif](../image546.gif) - apresenta opções comuns com as descrições de itens que poderão ser exibidos na tela:

*![image805.jpg](../image805.jpg)*

*Observações:*

1. Após a criação do Grupo, deve-se reiniciar o sistema para que seja vigorada a configuração.
2. O cadastro de Grupos de Usuários é compartilhado entre o Maker e o Webrun.

Saiba como reiniciar o sistema pelo tópico [Módulo de Configurações](modulo_configuracoes), utilizando o botão ![image547.gif](../image547.gif) (reinicia o serviço de acesso e processos do projeto selecionado).
