A tela de trabalho do Maker é composta pelos seguintes menus e comandos:

- Projeto - composto pelos principais comandos de configuração do projeto e gerenciamento de recursos. Observe as opções:
- - ![image20.gif](../image20.gif) (Ctrl+N)- permite criar um novo projeto;
  - ![image21.gif](../image21.gif) (Ctrl+A) - permite abrir um projeto;
  - ![image22.gif](../image22.gif) (Ctrl+Alt+S) - permite salvar o projeto em uso. Esta funcionalidade também pode ser executada efetuando um clique sobe o botão Salvar Tudo da [Paleta Objetos](paleta_objetos), quando houver um formulário aberto na área de trabalho do Maker;
  - ![image23.gif](../image23.gif) - permite regravar o projeto com um nome diferente;
  - ![image24.gif](../image24.gif)(Ctrl+F4) - permite fechar o projeto em uso;
- [Controle de Acesso](usuarios_do_sistema/usuarios_do_sistema) - este menu possui as opções de criação e gerenciamento de grupos e usuários que acessarão o Maker e os projetos desenvolvidos. Observe as opções contidas no menu:
- - ![usuarios](../image26.gif) (Ctrl+U) - permite a criação e edição dos dados de usuários do Maker e dos projetos;
  - ![grupos](../image29.gif) (Ctrl+G) - permite a criação e edição dos dados de grupos de usuários do Maker e dos projetos.
  - Trocar de Usuário - permite efetuar um logoff do Maker, solicitando um nome e senha de usuário.
  - Alterar Senha - permite modificar a senha do usuário logado no Maker.

Observação: Existem restrições para usuários da versão Standard Edition. Para mais detalhes, acesse o tópico [Recursos e Características das Versões do Maker](../recursos_e_caracteristicas_das_versoes_do_maker).

- ![dicionário de dados](../image30.gif) - permite a criação de apelidos para as tabelas, visões e campos. Obtenha mais informações acessando o tópico [Dicionário de Dados](dicionario_de_dados/dicionario_de_dados);
- ![tipos de dados](../image31.gif) - permite configurar máscaras para serem utilizadas na exibição de dados nos formulários. Obtenha mais informações acessando o tópico [Tipos de Dados](tipos_de_dados/tipos_de_dados);
- ![categorias do sistema](../image32.gif) - ativa a tela [Categorias do Sistema](categorias_do_sistema/categorias_do_sistema) permitindo editar modalidades novas ou existentes;
- ![galeria de imagens](../image33.gif)(Ctrl+I) - ativa o [Cadastro de Imagens](cadastro_de_imagens/catalogo_de_imagens) permitindo a sua utilização em operações diversas;
- ![conexões adicionais](../image34.gif) - permite estabelecer [Conexões Adicionais](configuracao_das_conexoes/conexoes_adicionais) com outros bancos de dados para o desenvolvimento do projeto em uso.

Observação: Existem restrições para usuários da versão Standard Edition. Para mais detalhes, acesse o tópico [Recursos e Características das Versões do Maker](../recursos_e_caracteristicas_das_versoes_do_maker).

- [Agendador de Tarefas](agendador_de_tarefas/agendador_de_tarefas) - permite agendar a execução de fluxos;
- ![versões](../image35.gif) - ativa a tela [Versionamento do Sistema](versoes/versionamento_de_sistema) permitindo o gerenciamento das versões do projeto;
- [Configurações](configuracao_das_conexoes/configuracoes) (tecla de atalho F6) - ativa a tela Configurações permitindo definir parâmetros de conexões do projeto, versionamento, acesso a serviços de aplicações e atualizações do Maker.

Observação: Existem restrições para usuários da versão Standard Edition. Para mais detalhes, acesse o tópico [Recursos e Características das Versões do Maker](../recursos_e_caracteristicas_das_versoes_do_maker).

- - Funções - permite criar e editar funções que farão parte do [Editor de Fluxo de Ações](fluxos_e_acoes/editor_de_fluxo_de_acoes).
  - Lista de Sistemas - lista os sistemas contidos no banco de dados. [Saiba mais...](lista_de_sistemas/lista_de_sistemas)
  - [Histórico de SQL](historico_sql/historico_sql) - apresenta todos os comandos de criações de campos e tabelas executadas na tela [Assistente de Banco de Dados](formulario/assistente_banco_dados).
  - [Empacotar projetos](empacotando_projetos/empacotando_projetos) - esta opção permite que o usuário possa gerar um pacote composto pelo banco de dados e o arquivo *.wfre, permitindo que o desenvolvedor instale o projeto em outra máquina.
  - ![sair do maker](../image36.gif) - fecha o projeto em uso e finaliza o Maker.
- Objetos - composto pelos principais comandos de manipulação de objetos do projeto:
- - Novo Objeto - permite criar um novo objeto no projeto atual:
  - - ![formulário](../image37.gif) - aciona a tela [Assistente de Criação de Novo Formulário](formulario/assistente_criacao_novo_formulario);
    - ![fluxo de ações](../image38.gif) - aciona o [Editor de Fluxo de Ações](fluxos_e_acoes/editor_de_fluxo_de_acoes);
    - ![relatório](../image39.gif) - aciona o [Maker Reports](relatorio/relatorios).
  - ![exportar](../image40.gif) (Ctrl+E) - permite a geração de arquivos de exportação de objetos do projeto. Obtenha mais informações acessando o tópico [Exportação](importacao_e_exportacao/exportacao);
  - ![importar](../image41.gif) (Ctrl+R)- permite implementar o projeto atual com a importação de objetos deste ou de outros projetos. Obtenha mais informações acessando o tópico [Importação](importacao_e_exportacao/importacao);
  - ![scanner de dependências](../image42.gif) (Ctrl+O)-  visualiza as dependências que envolvem os formulários, regras, tabelas e funções do projeto. [Saiba mais...](visualizador_dependencia);
  - ![histórico de alterações](../image43.gif) (Ctrl+H) - ativa a tela [Histórico de alterações de projetos do sistema](historico/historico_de_alteracoes_de_objetos_do_sistema), permitindo o gerenciamento das edições destes objetos.
- Utilitários - composto por ferramentas auxiliares do Maker para executar operações de:
- - ![editor de fluxo de ações](../image44.gif) (tecla de atalho F7) - ativa o [Editor de Fluxo de Ações](fluxos_e_acoes/editor_de_fluxo_de_acoes) para a criação de fluxos;
  - ![gerador de relatórios](../image45.gif) (tecla de atalho F8) - ativa o Maker Reports para a criação de relatórios;
  - Assistentes - composto pela opção ![criação de múltiplos formulários](../image46.gif) ([ir para tópico](formulario/criacao_multiplos_formularios));
  - ![otimizador de consultas](../image47.gif) - ativa a tela [Otimizador de Consultas](otimizador_consultas/otimizador_consultas);
  - ![atualizar lista de tabelas](../image50.gif) (tecla de atalho F5) - ativa o recurso de [Atualização da Lista de Tabelas](atualizacao_lista_tabela/atualizacao_lista_tabelas);
  - ![executor de scripts sql](../image48.gif) (tecla de atalho Ctrl+Q)- ativa a tela [Executor de Scripts SQL](executor_scripts_sql/executor_scripts_sql);
  - ![editor de fórmulas](../image844.gif) - permite que o desenvolvedor crie fórmulas para serem aplicadas ao projeto. Já que este recurso segue o legado, aconselha-se a utilização do [Editor de Fluxos de Ações](fluxos_e_acoes/editor_de_fluxo_de_acoes);
  - ![verificar atualizações](../image49.gif) (tecla de atalho F4) - ativa a tela [Update Maker 2](atualizacoes_maker/atualizacoes_maker);
  - Verificar atualizações do Help - verifica e baixa a versão mais nova do Manual do Maker, atualizando o arquivo Maker.chm que se encontra na pasta C:\Arquivos de programas\Softwell Solutions\Maker 2.7;
  - [Documentação](documentacao/documentacao_automatica) - Este recurso gera automaticamente uma documentação completa do projeto. Saiba mais acessando o tópico [Documentação automática](documentacao/documentacao_automatica);
  - [Exportar relatórios para Jasper](exportar_para_jasper/exportando_relatorios_para_jasper) - ativa o recurso de exportação de relatórios para Jasper.
- Ajuda - permite acessar itens sobre auxílio e informações de uso do Maker:
- - ![ajuda do maker](../image51.gif) - ativa o Manual do Maker, abrindo no tópico [Bem-Vindo](../bem_vindo) do arquivo de help. Ao pressionar F1 o Manual do Maker será aberto.
  - ![como faço para](../image52.gif) - ativa o Manual do Maker, abrindo no tópico [Tour do Maker](../tour) do arquivo de help;
  - ![o que há de novo](../image53.gif) - ativa o Manual do Maker, abrindo no tópico [O que há de novo?](../whatisnew) do arquivo de help;
  - ![maker na web](../image54.gif) - acessa o site da [Softwell Solutions](http://www.softwell.com.br/web/), na página que comenta sobre o Maker;
  - Comunidades - acessa uma lista de sites com conteúdo referente ao Maker.
  - ![sobre o maker](../image55.gif) - apresenta uma tela de identificação do Maker instalado: Licença, Número de Série e Versão.

Observações:

1. O recurso ![importação de usuários e senhas](../image833.gif)  e ![importação de arquivos rtm](../image834.gif) foram retirados na versão 2.5 do Maker. Para usuários que necessitem desse recurso, deverão solicitar ao [Suporte ao Maker](../suporte_ao_maker);
2. Existem restrições para usuários da versão Standard Edition. Para mais detalhes, acesse o tópico [Recursos e Características das Versões do Maker](../recursos_e_caracteristicas_das_versoes_do_maker).
