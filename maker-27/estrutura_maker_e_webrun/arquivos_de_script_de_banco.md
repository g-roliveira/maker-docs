São arquivos responsáveis pela criação do banco de dados na geração de um novo projeto.

- script-MySQL.sql
- script-ORACLE.sql
- script-MSSQL.sql
- script-Interbase.sql
- script-POSTGRESQL.sql

Deve-se observar que, para as versões novas do Maker, referentes ao SQL Server, temos o arquivo script-MSSQL-v2.1-update.sql.
