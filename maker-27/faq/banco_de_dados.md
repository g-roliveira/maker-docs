## Quais os bancos de dados suportados?

- PostgreSQL 8.2.5/8.3/8.4/9.0;
- MS-SQL Server 2005/2008/2008 R2;
- Firebird 2.0/2.1/2.5;
- Oracle 9i/10 g Enterprise XE/11g;
- MySQL 5/5.1/5.5;
- DB2 9.5

## Como funcionam as tarefas de gerenciamento do banco pelo Maker?

No Maker, existe o Assistente de Banco de Dados, onde é possível criar ou adicionar novos campos, constraint e etc à estrutura de uma tabela (tabela do banco de dados sobre o qual o projeto foi criado) a partir de um formulário.

E para as seleções, junções, uniões e etc, existe o Assistente SQL, que é um utilitário visual para auxílio na construção de consultas em linguagem SQL

## Existe alguma interação com ferramentas Case para modelagem de dados?

Não é necessária essa integração. O Maker trabalha com dicionário de dados e direto com tabelas do banco.

## É necessário instalar e configurar aplicações baseadas no modelo Cliente/Servidor?

A instalação do banco de dados é feita no servidor. Ele é que faz o envio dos dados para os clientes conectados. Esse modelo é utilizado juntamente com a tecnologia Java, integrado com os protocolos HTTP e SOAP.
